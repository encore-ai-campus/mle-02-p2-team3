# PDF 검수 기준 정리

## 기본 검수 범위
- 본문 텍스트
- 표 내부 텍스트
- 각주 및 주석
- 부록
- 이미지 OCR
- 스캔본 OCR
- 부분 일치 및 띄어쓰기 변형
- 유사 표현 탐색

## 결과 형식
| 항목 | 내용 |
|---|---|
| 발견 여부 | O/X |
| 페이지 | 페이지 번호 |
| 실제 문구 | 원문 |
| 문맥 | 주변 3~10줄 |
| 유형 | 텍스트 / 이미지(OCR) |

## 추가 검수 항목

### 1. 브랜드 선택 여부
- VISA 선택 가능 여부
- Mastercard 선택 가능 여부
- 브랜드 선택형 상품 여부

### 2. Fragment(문장 조각) 탐지
- 쉼표로 시작하는 조각
  - 예: `, 연 6회 제공`
- 단어 중간부터 시작
  - 예: `피, 주차 할인서비스는`
- 조사로 시작
  - 예: `는 서비스 제공`
- 문장 뒷부분만 존재

### 3. 노이즈 탐지
- HTML 태그
  - `<br>`
  - `<br aria-hidden="true">`
  - `</div>`
- OCR 깨짐 문자
- 의미 없는 텍스트 조각

### 4. Boilerplate(일반 안내문) 분리
- 가족카드 안내
- 연회비 반환 규정
- 고객센터 안내
- 법률/고지 문구
- 부가서비스 변경 안내

### 5. 수수료 안내 문장 분리
- 해외서비스 수수료
- 국제브랜드 수수료
- ATM 인출 수수료
- DCC 안내

### 6. 기대값 품질 평가
#### 정상
- `매출 건당 1천원, 통합 월 5천원까지 할인`

#### HTML 오염
- 정상 문장 뒤에 `<br aria-hidden="true">` 포함

#### 모호(Ambiguous)
- 기대값이 둘 이상 존재
- 예: `1%` vs `없음`
- 적립률과 적립한도가 동시에 존재하는 경우

## 판정 체계
| 항목 | 판정 |
|---|---|
| 기대값 존재 | O/X |
| 문장 완결성 | O/X |
| 브랜드 선택 여부 | O/X |
| Fragment 존재 | O/X |
| HTML 오염 | O/X |
| OCR 깨짐 | O/X |
| Boilerplate | 플래그 |
| 수수료 문장 | 플래그 |
| 다중 정답 | 플래그 |
| 모호성(Ambiguous) | 플래그 |
