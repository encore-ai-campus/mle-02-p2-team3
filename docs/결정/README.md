# 현재 유효한 결정 기록

- 이 문서의 목적: 현재 작업 방향과 아직 팀 합의가 필요한 항목을 빠르게 확인한다.
- 마지막 확인일: 2026-11-05
- 상태: 코드·이력에서 직접 확인한 내용과 제안·추정을 분리한다. 이력에서 날짜를 찾지 못하면 날짜 미확인으로 둔다.

## 1. 사용법과 상태

결정이 실제로 정해졌거나 현재 작업 원칙으로 쓰이는 항목을 기록한다. “실험 중”은 결과에 따라 바뀔 수 있고, “합의 대기”는 팀 확인 전 적용 범위를 넓히지 않는다. “폐기”는 과거 선택으로 유지하지 않는다. “제안”은 검토 전이다. 근거 이력은 당시 기록이며 현재 코드/DB 상태를 보증하지 않는다.

## 3. 합의 대기

- `public.fp_*`를 팀 그래프의 임시 공간으로 계속 쓸지, 팀 장부 스키마로 옮길지.
- `file_pipeline` 장부 계약: `SEED_TEST` 운영 여부, ID 발급, V6/V7/실제 DB 정합성, staging PK `stg_item_seq` 해결.
- 체크카드·약관 포함 범위, OCR 교차검증, main 병합 시점.
- D5 중복 정규화 기준과 D14 3회 비교·구간 채점 방식의 팀 합의.

## 4. 변경 규칙

결정이 바뀌면 이 표와 영향받는 코드·런북·설계 문서를 같은 커밋에서 갱신한다. 이 문서는 작업이력의 사실을 요약하며 공유 인덱스 갱신은 별도로 반영한다.

### 링크 확인

이 문서 작성 시 링크 대상 파일의 저장소 내 존재 여부를 확인한다. 링크는 `docs/작업이력/`의 실제 파일명이다. 링크 존재 재검증 결과는 작업이력에 기록한다.
