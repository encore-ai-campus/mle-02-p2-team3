## 읽는 법

- 수치와 상태는 인용한 저장소 문서 기준이다. 해당 문서와 링크 대상의 존재는 직접 확인했으며, PDF·실행 결과를 새로 열거나 재집계하지 않았다.
- 청킹 기준 수치 차이는 임의로 통합하지 않았다. AI 판정, 사람 대조, 미검토 상태를 서로 다른 결과로 읽는다.
- 전체 흐름은 [프로젝트 지도](프로젝트-지도.md)를 참고한다.
