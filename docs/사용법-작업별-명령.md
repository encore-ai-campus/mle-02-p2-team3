## 먼저 알아 둘 것

| 주의 | 이유와 방법 |
|---|---|
| `.env` 를 셸 `source` 로 읽지 않는다 | `.env` 는 윈도우 줄 끝(CRLF)이라 값 끝에 `\r` 이 남아 DB 이름이 `postgres\r` 이 된다. 키가 필요한 명령은 `python-dotenv` 로 읽는 래퍼(`~/pilot_work/with_env.py`)나 아래 스크립트를 쓴다 |
| 챗봇은 `streamlit run` 으로 실행한다 | `chat/app_v2.py` 를 직접 실행하면 팀 `llm.py` 의 anthropic 임포트 오류가 난다. 진입점은 `run_fp_chat.py`, `run_fp_chat_v2.py` |
| 평가·로그 도구의 출력은 `/tmp` 아래만 허용 | 개인정보 보호용. `/tmp` 는 재부팅하면 사라지므로 끝나면 `~/pilot_work/` 로 복사한다 |
| DB 에 쓰는 명령은 사용자만 실행한다 | `graph.load --execute`, `delete-run` 등. 기본은 dry-run(DB 접속 없음) |
| OpenAI 호출은 비용이 든다 | `--execute` 가 있을 때만 호출. 비용 상한(`--max-cost-usd`, `--max-estimated-tokens`)을 건다 |

### 챗봇 옵션(환경 변수, 명령 앞에 붙임)

| 변수 | 효과 | 기본 |
|---|---|---|
| `FP_QA_LOG=/tmp/qa-logs/x.jsonl` | 질문·답변·출처 위치 기록(`/tmp` 아래만) | 꺼짐 |
| `FP_ANSWER_FORMAT=v3` | 같은 대상의 다른 수치를 모두 나열하고 쪽을 표기 | v2 |

| `FP_SEED_UNION=1` | 질문의 카드명·키워드로 시드 노드 추가(A/B 에서 효과 확인 못 함) | 꺼짐 |
| `FP_MAX_COST_USD`, `FP_LLM_SLEEP` | 챗봇 호출 비용 상한·호출 간격 | 코드 기본값 |

## 자주 틀리는 것

| 실수 | 올바른 방법 |
|---|---|
| 명령 앞에 `~` 를 붙임(`~bash`) | `bash` 만 입력 |
| `.env` 를 `set -a; . ./.env` 로 읽음 | 쓰지 않는다(CRLF). 래퍼·스크립트 사용 |
| 오염된 터미널에서 DB 접속 오류(`database "postgres\r"`) | 새 터미널을 열거나 `unset DB_URL DB_URI FP_DATABASE_URL OPENAI_API_KEY` |
| 평가 출력 경로를 `~/pilot_work` 로 지정 | `/tmp` 아래로 쓰고 끝나면 복사(스크립트가 자동 복사) |
| 추출을 한꺼번에 큰 범위로 실행 | 먼저 `--max-chunks 10` 으로 비용을 가늠하고 이어하기로 나머지 실행 |

## 확인하지 못한 것

- 위에서 "도움말만 확인"한 명령은 인자 형식만 확인했고 실제 실행 결과는 확인하지 않았다.
- 44개 진입점 중 `extraction/` 의 보고·검토 도구(`*_report`, `*_review`, `consensus`, `prompt_version_compare` 등 약 10개)는 일회성 분석용으로 보이나 '더 이상 쓰지 않음'을 확인한 것은 아니다.
- 폴더 구조 정리(파일 이동)는 하지 않았다. 작업 카드 방식으로 설명서만 정리했다.
