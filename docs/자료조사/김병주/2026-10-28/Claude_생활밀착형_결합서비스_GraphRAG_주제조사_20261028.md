### P1. 장애인·고령자 이동·생활 보조기기 제도 결합 내비게이터 ★ 1순위(조건부)

| 항목 | 내용 |
|---|---|
| 대상 사용자 | 전동휠체어·의료용 스쿠터·수동휠체어·욕창예방매트리스·자세보조용구가 필요한 등록장애인과 **보호자(성인 자녀)**, 주민센터·복지관 상담 인력 |
| 해결할 문제 | 같은 보조기기라도 지원 경로가 여러 개다(건강보험, 의료급여, 보조기기 교부사업, 노인장기요양 복지용구 등). 제도마다 **대상자, 부담률, 내구연한, 등록 제품·업소 조건, 중복 제한**이 다르다. 사용자는 "우리 상황에서 어떤 제도로, 어떤 제품을, 언제 받을 수 있고 내 돈은 얼마인가"를 알고 싶어 한다 |
| 이용 시나리오 | 보호자가 입력: "어머니, 지체장애 등록, 작년까지 의료급여 수급자였다가 올해 건강보험으로 전환, 2023년에 의료급여로 전동휠체어를 받음, 배터리 교체 필요." → 출력: ① 전동휠체어 재급여는 내구연한을 **의료급여 지급 이력과 연계해 산정**함(별표7 4.나) → 아직 불가 ② 전지는 **본체 구입 후 1년 6개월이 지나면** 소모품 급여 대상(별표7 1.자) ③ 건강보험 급여 계산식은 min(유형별 고시액, 제품별 고시가격, 실구입가) × 90%이며, 차상위 경감 대상이면 100% ④ 공단 **등록 판매업자**에서 사야 함. 각 결론 옆에 조문·고시·제품코드 근거를 표시 |
| 결합 대상 | 사용자 자격(건보/의료급여 종별/차상위/장애유형) × 제도 × 품목유형 × 제품(표준코드·고시가격·고시 버전) × 소모품 × 판매업소 × 제도 간 연계·중복 규칙 |
| 노드 | `UserStatus`, `Scheme`(건보 급여, 의료급여, 교부사업, 복지용구), `Rule`(조문·고시 조항), `DeviceType`(전동휠체어 가군 등), `Product`(표준코드), `PriceNotice`(고시 번호·버전), `Consumable`(전지 등), `Vendor`(등록 판매업자), `Prescription`(처방전 서식) |
| 관계 | `(UserStatus)-[:ELIGIBLE_FOR]->(Scheme)`, `(Scheme)-[:COVERS]->(DeviceType)`, `(DeviceType)-[:HAS_DURABILITY {years}]->(Rule)`, `(Product)-[:OF_TYPE]->(DeviceType)`, `(Product)-[:PRICED_IN {price}]->(PriceNotice)`, `(Consumable)-[:REQUIRES_AFTER {months:18}]->(DeviceType)`, `(Scheme)-[:LINKS_HISTORY_WITH]->(Scheme)`(의료급여↔건보 내구연한 연계), `(Scheme)-[:EXCLUDES_IF_RECEIVED]->(Scheme)`(교부사업 중복 제한), `(Rule)-[:REQUIRES]->(Prescription)` |
| 대표 질문 | ① "의료급여로 받은 전동휠체어가 있는데 건강보험으로 바뀌면 다시 받을 수 있어?" ② "KP-31 전동휠체어를 건강보험으로 사면 내 부담금은? 차상위면?" ③ "건강보험으로 휠체어를 받았는데 지자체 보조기기 교부사업으로 욕창예방매트리스도 받을 수 있어?" |
| 공식 데이터 | 6장 P1 참조 (원본 4종 [실측]) |
| 경쟁 서비스 | 국민건강보험공단 보조기기 급여 안내 페이지(https://www.nhis.or.kr/static/html/wbma/c/wbmac0206.html, [검색]): 제도 설명. 중앙보조기기센터(교부사업 상담, [검색]). 이로움돌봄 앱: **장기요양 복지용구** 한도 잔액과 구매 가능 품목 표시([검색], https://www.theteams.kr/teams/636534/post/74047). 블로그형 계산기(https://glasswallet.com/calculate/hearing-aid-cost/subsidy, [검색]). **여러 제도를 교차해 중복·연계·제품 가격까지 계산하는 공개 서비스는 [검색]으로 찾지 못함** (미지원이라고 단정하지 않음) |
| ChatGPT 대체 가능성 | 일반 규칙(90% 지원, 등록업소, 5년 1회 등)은 잘 답할 것으로 추정. 의료급여→건보 내구연한 연계, 제품별 2026년 고시가격, 소모품 시기처럼 **두 문서 이상과 제품 표를 함께 봐야 하는 질문**은 틀릴 가능성이 높다고 추정. **실제 미검증** |
| 구현 난이도 | 중간. 원본이 PDF·CSV·XML로 확보됨. 규칙 문장(조문)을 관계로 옮기는 작업은 **수작업 검수**가 필요함(조항 30~50개 수준으로 추정) |
| 차별성·탈락 위험 | ① 규칙 대부분이 표·조건문이라 **SQL·규칙 엔진으로 충분**하다는 반박 가능성 ② 대상 판정에 의사 처방·장애 정도 기준이 걸려 있음 → "판정"이 아니라 "근거 안내"로 한정해야 함 ③ 교부사업 중복 제한의 **공식 원문을 확보하지 못함**(2차 자료만) ④ 보호자 사용자 수요는 직관적이지만 실사용 검증이 없음 |

### P3. 가공식품 알레르기 회피·대체품 추천

| 항목 | 내용 |
|---|---|
| 대상 사용자 | 식품 알레르기 아이를 둔 부모, 알레르기 당사자 |
| 문제 | "이 과자에 땅콩이 있나"는 표시를 보면 된다. 하지만 "같은 종류에서 땅콩·우유가 없고, 회수 이력도 없는 대체품"을 찾으려면 제품→원재료→알레르기 유발물질→같은 유형의 다른 제품→회수 이력을 거쳐야 함 |
| 노드·관계 | `Barcode` –`IDENTIFIES`→ `Product`(품목제조보고번호) –`CONTAINS`→ `Ingredient` –`IS_ALLERGEN`→ `Allergen`; `Product` –`OF_CATEGORY`→ `FoodType`; `Product` –`RECALLED_IN`→ `Recall` |
| 대표 질문 | ① "우리 아이는 우유·땅콩 알레르기야. 이 바코드 과자 대신 먹을 수 있는 같은 종류 과자는?" ② "이 제품 제조사가 최근 회수된 적 있어?" |
| 공식 데이터 | 식품안전나라 Open API: I2570(유통바코드 ↔ 품목제조보고번호) [실측, 바코드 `8809360172547` → 보고번호 `201204020263`]. C002(품목제조보고 원재료)는 샘플키 한도 초과로 **미확인**. I0490 회수(품목제조보고번호 필드 있음, 빈 값 많음) [실측, 이전 조사] |
| 경쟁 | 식약처 **푸드QR**(2024-11 출시, 표시사항·회수·알레르기 정보 제공, [검색] https://food.chemlinked.com/news/food-news/south-korea-launches-food-qr-for-easier-access-to-food-safety-information), 민간 앱 '식품안전정보'([검색]). **대체품 추천 기능은 [검색]에서 찾지 못함** |
| ChatGPT 대체 | 특정 바코드의 원재료는 모를 것(추정). 대체품 추천은 일반론만 가능할 것(추정, 미검증) |

### P7. 전기차 충전 호환·충전소·보조금

### P8. 출산·육아 지원제도 결합 (부모급여·아동수당·첫만남이용권 등)

### P9. 자동차 리콜·무상수리 ↔ 내 차

- 질문: "내 차가 리콜 대상이야? 같은 부품을 쓰는 다른 차종은?"

### P10. 스마트홈 기기 Matter 호환 + 국내 전파인증

## 5. GraphRAG 필요성 점검 (요청서 5장 기준)

| 점검 항목 | P1 보조기기 | P3 식품 알레르기 | P2 보청기 |
|---|---|---|---|
| 2~3단계 이상 탐색 | 예: 사용자 상태 → 제도 → 연계 제도 이력 → 품목 내구연한 → 제품 가격 버전 (4~5단계) | 예: 바코드 → 제품 → 원재료 → 알레르기 / 제품 → 유형 → 대체 제품 → 회수 (3단계) | 약함: 모델 → 제도 → 규칙 (2단계) |
| 여러 출처 연결 | 예: 시행규칙 별표 2종 + 고시 2종 + 공단 CSV (**표준코드로 121건 연결 실측**) | 예: 바코드 API + 원재료 API + 회수 API (원재료 API는 미확인) | 일부: CSV + 별표 (호환 데이터는 미개방) |
| SQL·일반 RAG로 부족한가 | **부분적으로만 부족.** 제품·가격은 SQL로 충분. 그래프의 가치는 **제도 간 연계·중복 규칙을 경로로 설명**하는 데 있음. 반박 가능성 큼 | 부분적. 대체품 탐색은 그래프 이웃 탐색이 자연스럽지만 SQL 필터로도 가능 | 부족하지 않음(대부분 1회 조회) |
| 조건 변경 시 결과 변화 | **큼**: 의료급여↔건보, 차상위 여부, 이전 수령 이력, 구입일이 바뀌면 결론과 금액이 달라짐 | 큼: 알레르기 종류에 따라 대체품이 달라짐 | 작음 |
| 원본 근거 제시 | 예: 별표 조항 번호, 고시 번호(제2026-57호), 제품코드 | 예: 보고번호, 회수 일련번호 | 일부 |

**그래프를 제거하면 잃는 것 (P1)**: 결과 금액 자체는 계산기로 낼 수 있다. 잃는 것은 **"왜 안 되는지/왜 이 금액인지"의 경로 설명**과 **제도 사이 연결**(의료급여 이력이 건보 내구연한에 영향, 교부사업이 다른 제도 수령 이력에 막힘)이다. 이 차이를 시연으로 보여 주지 못하면 GraphRAG 근거가 약해진다.

## 9. 1순위 추천과 근거

### 1순위(조건부): **장애인·고령자 이동·생활 보조기기 제도 결합 내비게이터**

사용자에게 보이는 질문: "**우리 가족 상황에서 이 보조기기를 어떤 제도로, 언제, 얼마에 받을 수 있나? 안 된다면 왜이고, 대안은?**"

1. **카드 추천처럼 쉬운 입력과 복잡한 내부 구조**: 입력은 몇 가지 상태값(보험 자격, 차상위 여부, 이전 수령 이력과 날짜, 원하는 기기)이다. 내부에서는 법령 별표 2종, 고시 2종, 공단 CSV를 연결해야 한다.
2. **관계가 실제로 존재한다**: 의료급여 별표가 건보 시행규칙 고시를 참조하고, 건보 별표가 의료급여 이력과의 내구연한 연계를 규정한다. 제품은 법령이 정한 표준코드로 고시와 CSV를 잇는다(121건 일치 실측).
3. **조건이 바뀌면 답이 바뀐다**: 이는 시연 가치가 크다(예: 차상위 → 90%에서 100%로, 의료급여 이력 → 재급여 불가).
4. **원본 근거를 보여 줄 수 있다**: 각 결론 옆에 별표 조항, 고시 번호, 제품코드를 표시할 수 있다.
5. **제외 대상을 피한다**: 카드·부동산·레시피와 무관하다. 의료 진단은 하지 않는다(처방 필요 여부만 안내).

### 솔직한 약점

- **차별성 미실증**: ChatGPT 실측을 하지 않았다. 공단 상담(1577-1000)과 주민센터 상담이 사실상 같은 일을 사람이 한다.
- **그래프 필요성이 경계선에 있다**: 금액 계산은 SQL·규칙 엔진으로 충분하다. GraphRAG의 근거는 "제도 간 연계·중복 경로 설명" 하나에 걸려 있다.
- **중복 제한 공식 원문 미확보**: 교부사업의 중복 제한은 2차 자료로만 확인했다. 원문을 못 구하면 핵심 관계 하나가 빠진다.
- **사용자 수요 미검증**: 보호자 커뮤니티 질문 사례를 수집하지 않았다.

## 10. Go / No-Go 조건 (다음 단계)

| # | 확인할 것 | Go 조건 | No-Go 시 |
|---|---|---|---|
| 1 | 4장 P1 질문 1·2를 ChatGPT(웹검색)·Perplexity에 실제로 질문 | 근거 조문 연계(4.나)나 2026년 제품 고시가격을 **틀리거나 못 찾음** | 정확히 답하면 P1 탈락 |
| 2 | 보건복지부 「장애인 보조기기 교부사업 안내」 원문 PDF 확보, 중복 제한 조항 확인 | 다른 제도 수령 품목을 제외하는 문장과 조건이 원문에 있음 | 없으면 제도 간 관계가 연계 규칙 1개로 줄어듦 → 그래프 필요성 재평가 |
| 3 | 세부사항 고시 별표(유형별 기준액·내구연한) 파싱 + 등록 판매업자 공식 목록 존재 여부 | 품목유형 20개 이상의 기준액·내구연한 추출 | 수작업 입력 범위가 커지면 MVP 범위 축소 |

**1과 2가 모두 불리하면 '적합한 주제 미발견'으로 보고한다.** 그때 P3는 C002 원재료 API에서 알레르기 표시를 구조적으로 얻을 수 있는지 확인한 뒤에만 다시 검토한다.

**MVP 범위 제안 (Go일 때)**
- 포함: 전동휠체어·의료용 스쿠터·수동휠체어·욕창예방매트리스 4개 품목, 건보·의료급여 2개 제도(+교부사업 중복 제한 1개 관계), 2026년 고시 제품 약 100개, 조건 입력 → 가능/불가 + 금액 + 경로 근거
- 제외: 장애 정도 판정, 처방 적합성, 지자체별 추가 지원, 실시간 판매업소 재고
