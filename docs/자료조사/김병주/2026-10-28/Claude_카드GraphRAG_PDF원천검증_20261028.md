# 카드 GraphRAG — 공식 PDF 원천 확보 및 관계 검증

| 항목 | 내용 |
|---|---|
| 작성자 | Claude (Opus 5.5, Claude Code) |
| 작성일 | 2026-10-28 |
| 문서 버전 | v1 |
| 검증 범위 | 카드사 공식 사이트의 상품 상세 페이지에서 상품설명서 PDF 링크를 추적했다. PDF를 직접 내려받아 텍스트 추출과 페이지 이미지 대조를 함께 했다. Q1~Q3를 문서 근거로 답할 수 있는지 판단했다 |
| 하지 않은 것 | 토스·경쟁 서비스 조사, 계산, 구현 |
| 기존 보고서 | 수정하지 않았다. 다른 AI 보고서의 결론은 근거로 쓰지 않았다 |

**표기 규칙**

- 페이지는 **PDF 파일의 실제 페이지 번호**다. 하나카드 PDF는 펼침면 구성이라 인쇄 쪽번호와 다르다. 예: PDF 3쪽 = 인쇄 2~3쪽.
- 확인 방식
  - **T** = 텍스트 레이어 추출만으로 확인
  - **T+I** = 텍스트 추출 + 페이지 이미지 대조
  - **I** = 텍스트 레이어가 없어 이미지로만 확인

## 1. 최종 판정

**조건부 통과**

- 정식 상품설명서 PDF 4종을 확보했다(신용 2종, 체크 2종, 카드사 2곳).
- 4종 모두 카드사 공식 상품 페이지의 링크에서 2026-10-28에 직접 내려받았다.
- 카드별 핵심 관계를 3개 이상 원문 페이지로 확인했다.

최종 판단 질문에 대한 답은 다음과 같다.

| 질문 | 답변 가능성 |
|---|---|
| Q1 | **가능.** 혜택·결제 방식·제외 조건을 여러 카드에 걸쳐 관계로 연결해 설명할 수 있다 |
| Q2 | **가능.** 단 같은 상품의 신용·체크 전환이 아니라 "다른 상품 간 비교"다 |
| Q3 | **부분 가능.** 4종 중 할인 적용분 실적 제외를 명시한 문서는 1종(KB WE:SH All+)뿐이다. 나머지 3종은 '미기재'다 |

**"조건부"인 이유**

1. **KB WE:SH All+ 상품설명서는 본문 대부분이 이미지다.** 텍스트 추출로는 혜택·제외 조건을 거의 얻을 수 없다(1쪽 827자, 2쪽 195자).
2. **체크카드 2종이 모두 KB국민카드다.** 하나카드 체크카드 상품설명서는 확보하지 못했다.
3. **Q3 비교 대상이 빈약하다.** "할인 적용분 실적 제외"를 명시한 정식 문서는 1종뿐이다.
4. **하나카드 문서의 명칭이 엇갈린다.** 사이트 버튼은 '상품약관보기', URL 경로는 `/leaflet/`인데, PDF 1쪽 제목은 "제이드 클래식 상품설명서"이고 본문에도 "본 상품설명서는 …"이라고 적혀 있다. 이 보고서는 **문서 자체의 표기를 기준으로 상품설명서로 분류**했다.

**BC 정식 상품설명서 추적 결과**

- BC카드 공식 다운로드 경로(`/down/individual/customer/`)에서 확인한 9건은 모두 '리플렛'이다.
- BC 바로카드 상품 상세 페이지는 정적 HTML로 찾지 못해, 별도 상품설명서가 있는지 확인하지 못했다.
- 따라서 "BC 상품설명서가 존재하지 않는다"가 아니라 **"이번 경로로는 확보 실패"**다.

## 4. 사용자 질문 Q1~Q3의 답변 가능성

### PDF 원문만으로 답한 예시 — Q1 요지

- **간편결제를 자주 쓴다면 OTT 결제에 주의해야 한다.**
  - OTT 혜택이 있는 C-A·C-B·K-A는 모두 공식 홈페이지 정기결제(또는 자동납부)만 대상이다.
  - C-A와 C-B는 간편결제와 인앱결제를 **명시적으로 제외**한다(C-A p1, C-B p4).
  - K-A는 인앱결제를 제외하고(p1), PG·간편결제 전용 가맹점으로 분류된 결제를 할인에서 제외한다(p2).
- **간편결제 자체에 할인을 주는 카드는 K-B 첵첵 체크뿐이다.** 네이버·카카오·SSG페이 온라인 결제, 건당 2만원 이상이 조건이다(p1). K-B에는 OTT·통신 혜택이 없다.
- **K-A Youth Club 체크에서는 간편결제가 오히려 조건인 혜택도 있다.** 편의점 할인은 KB Pay로 결제해야 받는다(p1). 같은 '간편결제'라도 혜택에 따라 조건이 되기도 하고 제외 사유가 되기도 한다. 그래서 관계마다 적용 범위를 따로 저장해야 한다.
- **OTT와 통신을 함께 원하는 경우**
  - C-A는 한 카드에서 둘 다 제공한다(p1).
  - K-A는 OTT가 A팩, 통신이 B팩이라 **같은 달에 둘 다 받을 수 없다**(p1 + p2).
  - C-B는 통신 혜택이 없다.

### Q2 요지

- **유지되는 것:** 신용(C-A, C-B)이든 체크(K-A)든 OTT 혜택은 "공식 홈페이지 정기결제·자동납부만, 인앱 제외"라는 결제 경로 조건이 같다.
- **달라지는 것**
  - 혜택 형태: C-B는 하나머니 적립, C-A는 할인, K-A는 출금계좌 환급할인(p2)이다.
  - 동시 이용: K-A에서는 OTT(A팩)와 쇼핑멤버십·온라인몰(B팩)이 **월 택1**이다.
  - 온라인쇼핑 대상 몰: C-B는 쿠팡·컬리 등이고, K-A는 무신사·29CM 등 패션몰이다.
  - 실적 기준: 신용은 40만·50만원, 체크는 20만·30만원이다.

### Q3 한계

- 4종 중 **C-A만** "자동납부 할인 적용 받은 매출"을 실적 제외로 명시한다(p2).
- 나머지 3종은 실적 제외 목록에 해당 문구가 없다.
- 그래서 비교 결과는 "명시 1 / 미기재 3"이 된다. 카드마다 조건이 다르다는 것은 보여줄 수 있지만, 대비가 약하다.

## 5. 남은 위험

1. **이미지 PDF:** C-A는 혜택·제외 조건 전부를 이미지로만 읽을 수 있다. LLM 후보 추출에는 비전 입력이나 사람 전사가 필요하다.
2. **문서 명칭 혼재(하나카드):** 버튼 '상품약관보기', 경로 `/leaflet/`, 문서 제목 '상품설명서'가 서로 다르다. 별도의 정식 약관(개별 상품 약관)이 따로 있는지는 확인하지 못했다.
3. **현행성:** 4종 모두 현재 카드사 상품 페이지에 링크되어 있다. 그러나 **신규 발급 가능 여부와 이후 개정 여부는 확인하지 못했다.** 문서 날짜는 파일명과 메타데이터 기준이다.
4. **체크카드 카드사 편중:** 체크카드 2종이 모두 KB국민카드다.
5. **Q3 근거 부족:** 실적 제외를 명시한 정식 문서는 1종뿐이다.
6. **적용 범위 오해석:** 같은 '간편결제'가 Y5에서는 가맹점 분류에 따른 제외, Y6에서는 KB Pay 조건, H1에서는 할인 대상, H3에서는 '타' 간편결제 제외다. 관계마다 범위를 저장하지 않으면 잘못 일반화된다.
7. **표 병합 셀:** C-B p3 적립률처럼 병합 셀이 있는 표는 텍스트 추출만으로 행과 열을 잘못 연결할 수 있다. 이미지 대조가 필요하다.
8. **페이지 번호 차이:** 하나카드 PDF는 PDF 페이지와 인쇄 쪽번호가 다르다. 출처는 반드시 PDF 페이지로 저장해야 한다.

## 6. 다음 작업 권고

**판정이 조건부 통과이므로, 아래를 먼저 처리한 뒤 토스 동일 질문 비교 검증으로 넘어간다.**

1. **강사 확인**
   - 카드사 상품설명서 PDF를 데이터 원천으로 써도 되는지(OpenDART-only 예외)
   - 하나카드 문서를 상품설명서로 인정하는지
2. **체크카드 다양화(권장):** 하나카드 등 KB 이외 카드사의 체크카드 상품설명서 1종을 추가한다.
   - 하나카드 상품 페이지는 서버 렌더링이고 상품별 PDF 버튼이 있다.
   - 체크카드 목록의 상품 번호만 찾으면 같은 방식으로 확보할 수 있다.
   - 트래블로그, 달달 하나 체크의 상품 번호는 이번에 찾지 못했다.
3. **Q3 보강:** "할인·적립 적용분 실적 제외"를 명시한 정식 상품설명서 1종을 더 찾는다.
   - BC 바로 ZONE 리플렛(p2)에는 이 조건이 명시돼 있다. 그러나 리플렛이므로 **강사가 리플렛을 허용하지 않는 한 쓰지 않는다.**
4. **C-A 판독 방식 확정:** 비전 LLM 또는 사람 전사 중 무엇으로 할지 정한다. 정하지 못하면 C-A 대신 텍스트 레이어가 양호한 다른 KB·하나 신용카드 상품설명서로 교체한다.
5. 위 조건이 정리되면 **토스 카드라운지와 같은 질문(Q1~Q3) 비교 검증**을 진행한다.
