# 미래 생활계획 기반 카드 GraphRAG와 토스 차별화 실증 검증

- 문서 버전: v1, 독립 신규 보고서
- 검증 상태: 부분 검증. 토스 공개 웹페이지의 서버 제공 화면·문구를 새로 확인하고 공식 카드 PDF의 페이지별 텍스트를 대조했다. 브라우저에서 필터 클릭·비교함 담기·결과 화면을 직접 조작하지 않았으며, 모바일 앱 로그인 후 화면·사용자 실험·PDF 이미지 대조는 미검증이다.
- 확인일: 2026-10-28. 검색엔진에 저장된 페이지의 게시·갱신 시점은 다를 수 있다.

## 1. 한 페이지 결론

**토스 차별화 B / GraphRAG B / 전체 REFINE.** 미래 계획을 정성적으로 묻는 맥락은 유지하되, 차별화의 중심을 **여러 관심사의 혜택이 같은 기간에 함께 가능한지와 결제 경로별 제한을 문서별 근거로 점검하는 기능**으로 좁힌다. 이 가치는 시연 가능한 가설이며 토스가 제공하지 않는다고 입증된 기능은 아니다.

[토스 공식 소개](https://i18n.toss.im/service/card)는 실제 소비 기반 추천과 직접 비교를 설명한다. 하지만 공개 [OTT·구독 랭킹](https://card-lounge.toss.im/ranking/ott-subscription?filters=SAMSUNG&tab=ARTICLE)에는 과거 소비 연결 없이도 신용·체크 분류, OTT, 통신비, 온라인 쇼핑 등 관심 카테고리를 탐색할 수 있는 공개 링크가 보인다. 따라서 **‘토스는 미래 생활계획을 다루지 못한다’는 주장은 부정확하거나 최소한 입증되지 않았다.** 미래 계획을 현재의 관심사로 바꿔 필터와 상세 페이지에서 탐색하는 것이 가능하기 때문이다. 복수 필터의 실제 AND/OR 의미 및 상세 입력 UI는 조작하지 않아 미확인이다.

실제 [KB Youth Club 체크 상품설명서 1~2쪽](https://img2.kbcard.com/obj/card/download/04124__prdctOpmn_20260330.pdf)은 OTT가 A팩, 통신이 B팩이며 월별 선택 팩만 제공한다고 명시한다. 이 조항들을 조합하면 같은 달 두 선택 팩의 혜택을 모두 제공받을 수 없다는 결론이 나온다. [KB NEED Pay 설명서 1쪽](https://img2.kbcard.com/obj/card/download/09800__prdctOpmn_20260330.pdf)은 구독·멤버십의 간편결제 제외와 특정 멤버십·Pay 조합의 예외를 제시한다. 이런 **조건 관계의 자동 결합**이 프로젝트의 후보 가치다. 토스에 동일 기능이 있는지, 사용자가 실제로 더 쉽고 정확하게 이해하는지는 미검증이다.

SQL도 동일한 관계와 출처를 표현할 수 있다. Neo4j는 카드→혜택→팩/조건의 경로를 설명하는 교육적 구조로 적합하지만 성능·정확도 우위는 입증되지 않았다. 2인·3일에서는 승인된 핵심 4~6종과 고정 질문 유형으로 제한해야 한다.

## 3. 검증되지 않은 기능 목록

- 카테고리 여러 개를 동시에 선택할 수 있는지, 선택 시 교집합인지 합집합인지, 카드사·유형 필터와 결합 가능한지.
- 검색어로 ‘다음 달 넷플릭스·통신 자동납부’ 같은 계획을 입력하는지, 결과를 계획별로 보존하거나 비교하는지.
- 앱 로그인 후 카드 관련 자연어 대화·AI 탐색의 존재와 정확한 범위.
- Youth Club의 A/B 선택 충돌을 여러 조항에서 자동 결합하는지, 세부 혜택과 공통 결제 제외를 질문별로 합쳐 보여주는지.
- NEED Pay의 지정 멤버십·페이 예외를 다른 카드의 조건과 교차 분석하는지.
- 신용·체크를 한 비교함에 동시 담는 조작과 결과, PDF 원문·페이지 인용 기능.
- 실제 사용자에게 자동 판정이 검색 시간·누락·오답을 얼마나 줄이는지. 사용자 후기나 실험을 확보하지 못했으므로 실제 체감 효과는 가설이다.

## 4. 세 가지 미래 생활계획 질문의 토스 대비 수행 과정

아래 토스 과정은 공개 화면에서 **확인된 항목을 바탕으로 한 가능한 경로**다. 항목 클릭, 필터 조합 및 최종 비교 결과는 수행하지 않았으므로 ‘실제 완료된 사용자 흐름’으로 주장하지 않는다.

### 질문 1 — 구독 시작

> 다음 달부터 넷플릭스와 유튜브를 구독하고 통신비를 카드로 자동납부하려고 해. 간편결제도 계속 사용하고 싶은데 어떤 카드의 조건이 맞을까?

- 토스 경로: [OTT 분류](https://card-lounge.toss.im/ranking/ott-subscription?filters=SAMSUNG&tab=ARTICLE) 또는 카드 찾기에서 후보를 찾고 상세의 구독·통신·결제조건을 확인하고 비교함을 이용할 수 있다. 토스의 [K-패스 상세](https://card-lounge.toss.im/card/10235)는 OTT·통신과 직접결제·인앱 제외를 이미 제시한다. 실제 어떤 필터 조합이 가능한지는 미확인.
- 사용자의 판단: 각 혜택의 직접납부·결제경로, 공통 한도·전월실적, 팩 선택의 양립 여부를 각 카드별로 연결해야 할 수 있다. 토스 자동 분석 여부는 미확인.
- 신규 자동화 가설: Youth A팩 OTT/B팩 통신의 같은 달 선택 충돌과 NEED Pay의 디지털 혜택 결제 예외를 관심사별 표에 연결한다. 관련 [Youth PDF 1~2쪽](https://img2.kbcard.com/obj/card/download/04124__prdctOpmn_20260330.pdf), [NEED Pay PDF 1쪽](https://img2.kbcard.com/obj/card/download/09800__prdctOpmn_20260330.pdf).
- 판정 불가: 개인 실적 달성·발급 자격·실제 적용 및 어느 카드가 금액상 가장 유리한지. 자료가 없으면 동시 가능을 미확인으로 둔다. 기대 절약은 여러 페이지에서 연결된 조항을 찾아 정리하는 수고이며 실험되지 않았다.

### 질문 2 — 카드 유형 전환

> 앞으로 신용카드 사용을 줄이고 체크카드 중심으로 생활하려고 해. OTT와 온라인쇼핑 혜택을 함께 고려하면 어떤 제약이 있을까?

- 토스 경로: 공개 랭킹의 신용·체크 구분을 활용해 유형별 후보를 찾고 상세의 OTT·온라인몰 조건을 읽는 경로가 보인다. 혼합 비교함 조작 여부는 미확인. [토스 신한 국민행복 상세](https://card-lounge.toss.im/card/1605)는 온라인몰과 OTT의 개별 조건을 설명한다.
- 사용자의 판단: 각 카드의 지정 가맹점, 정기결제, 온라인몰과 팩 소속 차이를 비교. 현재 보유한 신용카드가 명시되지 않아 무엇이 실제 유지되는지는 양쪽 서비스 모두 확정할 수 없다.
- 신규 자동화 가설: [JADE 신용 PDF 3~4쪽](https://m.hanacard.co.kr/leaflet/14/14955_20260609.pdf)의 온라인몰·디지털 콘텐츠와 [Youth 체크 PDF 1~2쪽](https://img2.kbcard.com/obj/card/download/04124__prdctOpmn_20260330.pdf)의 A팩 OTT·B팩 온라인몰 및 택1을 질문별 표로 정렬. 공통 서비스와 조건의 차이를 원문과 함께 보여준다. 이는 개인별 최적 카드나 혜택 유지 보장이 아니다.

### 질문 3 — 결제 습관 변경

> 앞으로 오프라인 쇼핑보다 온라인 쇼핑과 간편결제를 많이 이용하려고 해. 카드 혜택이 제한되거나 예외로 적용되는 조건을 미리 알고 싶어.

- 토스 경로: [온라인 쇼핑·배달/간편결제 분류](https://card-lounge.toss.im/ranking/ott-subscription?filters=SAMSUNG&tab=ARTICLE)에서 관련 후보를 탐색하고 카드별 상세 조건을 읽는다. [신한 국민행복 상세](https://card-lounge.toss.im/card/1605)도 공식 앱 직접 접속 및 간편결제 가맹점명에 관한 조건을 제공한다.
- 신규 자동화 가설: [NEED Pay PDF 1쪽](https://img2.kbcard.com/obj/card/download/09800__prdctOpmn_20260330.pdf)의 온라인 패션몰 KB Pay 요구와 디지털 멤버십의 일반 페이 제외·지정 쌍 예외, [첵첵 체크 PDF 1쪽](https://img2.kbcard.com/obj/card/download/01914__prdctOpmn_20260818.pdf)의 온라인 간편결제 조건을 따로 표시한다. 같은 페이라는 단어가 요구와 제외에 각각 적용될 수 있음을 보여준다.
- 미확인: 실가맹점 등록명·PG 분류, 실제 혜택 적용·월별 실적, PDF 최신성. 사용자가 읽을 조항을 한 표로 모으는 편의는 가설이며, 토스와 직접 비교해 검증해야 한다.

## 5. 기능별 차별화 비교표

상태는 2절의 다섯 분류를 사용한다. 난이도는 **2인·3일, 사전 확보된 검수 PDF 4~6종** 전제의 판단이다. ‘차별화 가설’은 제품 가치나 토스 미제공의 입증이 아니다.

| 기능 | 토스 지원 상태·차별화 여부 | 근거와 예상 체감 가치 | GraphRAG 필요성 | 난이도 |
|---|---|---|---|---|
| 미래 계획 자연어 입력 | **접근 제한으로 검증 불가**. 차별화 가설 | 앱 입력 미확인; 공개 관심 카테고리는 이미 있음. 계획을 한 문장으로 입력하는 편의는 실험 필요 | 낮음. 폼·SQL·일반 RAG 가능 | 중 |

## 6. GraphRAG vs SQL vs 일반 RAG

| 접근 | Q1 Youth 팩 제약 처리 | 근거·비용·한계 |
|---|---|---|
| 일반 PDF RAG | OTT가 A팩, 통신이 B팩인 1쪽과 선택 1개인 2쪽을 같이 검색해 LLM이 설명 | 페이지 메타데이터로 출처 표시 가능. 관련 조각 누락·해석 오류 평가 필요. 구현은 비교적 단순 |
| 정규화 SQL + 조건 검색 | `card`, `benefit`, `pack`, `selection_group`, `rule`, `source_page`를 조인해 같은 달 택1 확인 | 관계 테이블·재귀 질의·예외·페이지 추적까지 가능. 동일 승인 데이터면 그래프와 같은 정답 가능 |
| Neo4j GraphRAG | `카드→OTT→A팩→선택그룹`과 `카드→통신→B팩→같은 선택그룹`을 각각 최대 3홉으로 조회해 비교 | 두 경로와 선택 제한의 근거를 보여주기 좋다. 각 사실을 승인해 출처를 연결해야 하며 모델·운영 비용 증가 |

공통 서비스 노드를 이용한 비교는 카드 간 직접 관계를 새로 만든 것이 아니다. 그래프가 SQL보다 빠르거나 정확하다는 측정은 없다. 정성 입력, 필터, PDF 인용, 단순 조건 비교는 그래프 전용 기능이 아니다. 사용자 가치 관점에서도 동일한 결과와 근거를 SQL로 보여줄 수 있다. GraphRAG의 이유는 팩·혜택·조건의 경로와 사람이 검토한 근거를 교육 목적으로 명시적으로 탐색한다는 점이다.

## 7. 2인·3일 MVP에 남길 기능

**핵심 1개:** 미래 계획의 정성 관심사 2~3개를 입력하면 승인된 4~6종에서 혜택별 결제조건과 선택 팩 충돌을 출처 페이지와 함께 비교한다. 카드별 조건이 모자라면 ‘미확인’으로 남긴다. 실제 실적·할인액·최적 카드는 판단하지 않는다.

**보조 최대 2개:** (1) 신용·체크 유형 필터, (2) 원문 페이지와 선택 충돌 경로 표시. 인앱·지정 페이 예외는 데이터가 검수된 1개 사례만 다룬다.

1일차: 두 사람이 공식 PDF 4종 확보·텍스트/이미지와 팩 범위 검수, 기존 Neo4j·Streamlit 구조 확인. 2일차: LLM 후보 추출, 사람 승인·거절, Neo4j 저장 및 고정 경로 질의. 3일차: Streamlit 질문·표, 다섯 사례의 원문/예외/미확인 테스트. 예상 일정이며 실측은 없다. LLM 추출 실패 시 사람이 작성·승인한 관계로 백업 시연하되 자동 추출 요건 미완료를 밝힌다. 10종 목표보다 4~6종 정확도를 우선한다.

## 8. 실패 가능성과 차별화가 무너지는 조건

- 토스 로그인 후 동일 질문에 대해 팩 충돌과 서비스별 페이 예외를 교차 설명하고 출처까지 제공하는 것이 확인되면, 제안한 차별화는 상당 부분 약해진다.
- 동일 카드와 질문으로 최소 5명의 탐색적 비교에서 신규 결과가 토스 대비 이해 정확도나 시간에서 실질적 개선을 보이지 않으면 주장 강도를 낮춘다. 5명은 시장 전체를 대표하지 않는다.
- 사용자가 미래의 금액·실적이나 실제 결제 혜택 예측을 원한다면 이 MVP는 그 질문에 답할 수 없다. 정성 관심사는 미래 예측 자체가 아니다.
- PDF가 오래되거나 조항·표가 잘못 추출되면 출처 링크가 있어도 결과가 틀릴 수 있다. 문서 해시·버전·원문 위치를 보관하고 승인 전 표를 이미지로 대조한다.
- ‘간편결제 제외’의 대상 혜택·가맹점 분류와 지정 페이 예외를 무시하면 결론이 반대가 된다. 미기재를 허용/동시 가능으로 바꾸지 않는다.
- 2인·3일에서 LLM 추출, 사람 승인, Neo4j, LangGraph, 출처 검증까지 완성하지 못하면 수동 승인 데이터로 관계 탐색만 시연하고 미완료 요건을 표시한다.
- 공식 카드 PDF와 기존 OpenDART-only 과제 조건의 충돌 및 공식 리플릿 사용 가능 여부는 강사에게 별도 확인한다.

## 9. 최종 A/B/C 및 GO/REFINE/PIVOT 판정

- **토스 차별화 B:** 미래 관심사 탐색은 토스에서 이미 가능한 범위가 있다. 복합 조건의 자동 판정과 설명은 가능성 있으나 토스 앱 전체와 비교한 결과는 없다.
- **GraphRAG B:** 공식 PDF의 선택 그룹과 혜택별 조건을 경로로 설명하기에 교육용으로 적합하다. SQL·일반 RAG도 같은 답을 만들 수 있고 실사용 우위는 미검증이다.
- **REFINE:** 미래 계획을 질문 맥락으로 유지하되, 검수된 4~6종의 선택 충돌과 결제방식 조건 비교에 집중한다. ‘토스에 없는 미래 추천’이라고 발표하지 않는다.

## 10. 강사 발표에서 사용할 수 있는 사실에 근거한 차별화 설명 5문장

1. 토스는 실제 소비를 기반으로 카드를 추천하고 공개 카드라운지에서 혜택 카테고리·카드 조건을 탐색하도록 제공한다.
2. 사용자는 미래에 원하는 OTT나 쇼핑 혜택도 토스의 카테고리와 상세 조건을 이용해 찾아볼 수 있다.
3. KB Youth Club 체크 설명서에는 OTT가 A팩, 통신이 B팩이고 월별 선택 팩만 제공된다고 명시돼 있어 두 조항을 함께 읽어야 한다.
4. 우리는 미래 계획을 정성적으로 입력받아 승인된 PDF의 팩·혜택·결제조건 관계를 연결하고 문서 페이지와 함께 충돌 여부를 보여주는 실험을 한다.
5. 토스에 동일 자동 분석이 없다고 단정하지 않으며, 사용자 비교 실험과 앱 검증으로 실제 차이를 확인하겠다.
