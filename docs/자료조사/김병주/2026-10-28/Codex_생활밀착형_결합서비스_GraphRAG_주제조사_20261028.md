# 생활밀착형 결합서비스 GraphRAG 신규 주제 재탐색

- 조사자: 김병주 / 작성 도구: Codex / 조사일: 2026-10-28
- 상태: **적합한 주제 미발견**, 주제 확정 보류
- 범위: 생활밀착형 10개. [주제 선정 규칙](../../주제_선정_규칙.md) 전문과 기존 신규 조사 보고서들을 읽었다. 요청한 단일 파일에 A~F 항목을 후보별로 통합했다. 기존 결과·코드·DB는 변경하지 않았다.
- 실측 정의: **공식 원문 온라인 내용 확인 10/10**, **규칙의 데이터 확보 필수조건 전체 충족 0/10**. 온라인에서 HTML·PDF 본문을 열어 확인한 것은 로컬 원본 파일 다운로드·독립 파싱 성공과 다르다. 이번 조사에서 원본 파일은 로컬에 확보하지 않았다. API JSON 실제 호출도 성공하지 못했다. 다운로드·추출·관계·활용 조건을 모두 확인해야 통과다.
- 경쟁 서비스는 공개 페이지·안내의 기능 설명을 확인한 것으로 실제 로그인·동일 조건 입력·결과 비교는 하지 않았다. 별도의 일반 ChatGPT 직접 질의도 하지 않았다. 경쟁 기능이 설명에 없는 것은 미지원의 증거가 아니다. 사용자 질문은 테스트용이며 기대 결과와 우위는 가설이다.
- 저작권·이용 조건: 공개 열람이 무료인 것과 자동수집·상업적 가공·재배포 허용은 다르다. 공공데이터 1종의 명시 조건을 제외하고 모든 후보의 자료별 권리 및 API 제한은 **미확인**이다. 조사 확인일은 본 보고서 작성일이며 자료의 갱신일·지역·버전은 각 링크에서 재확인해야 한다.

## 선행 조사에서 배운 점

- [Claude 신규 조사](Claude_신규GraphRAG_주제및유사서비스조사_20261028.md)는 기업 지원사업 공고의 자격·중복수혜 관계를 우선 검토하고, 금감원 제재 및 DART 전환사채 관계를 조건부 제안했다. 기존 맞춤 추천의 기능 중복, 문서별 연결·실제 ChatGPT 비교, CB 본문 파싱 등이 남았다.
- [Codex 신규 조사](Codex_신규GraphRAG_주제및유사서비스조사_20261028.md)는 FDA 510(k) 선행제품 경로를 조사 우선으로 두었으나 기존 계보 도구와의 중복 및 두 번째 연결 사례 미확인으로 확정을 보류했다. 취약점·라이선스는 전용 도구, 법령은 3단 비교와 중복 위험이 확인됐다.
- [이전 Claude 결과](2026-10-28_GraphRAG_주제조사_Claude.md)는 보안 권고문을 조건부 우선으로 삼았고, PDF 로컬 추출·이용조건 및 경쟁 서비스 비교를 미완료로 남겼다. 탈락 확정된 카드나 기존 분야의 이름만 변경하는 방법은 쓰지 않는다. 이번의 보청기는 사용자가 명시한 예시이며 기존 의료기기 리콜 분석을 변형한 주제가 아니다.

## 공통 검증 기준과 그래프 비교

각 경로는 실제 연결로 확인된 간선과 아직 가설인 간선을 구분한다. 정확한 모델명·국가·시점·제품 버전이 동일하다는 증거 없이 이름만 비슷한 제품은 합치지 않는다. 조건에 정보가 없으면 `미확인`을 반환하고, 무목록을 비호환으로 바꾸지 않는다. 출력은 가능한 한 출처 URL, 문서명·게시일/확인일, 조항/페이지, 모델·지역·시점을 함께 제시한다.

관계가 2~3단계라고 해서 SQL이 불가능한 것은 아니다. 좁고 고정된 매칭은 SQL 조인·규칙 엔진이 간단할 수 있다. 일반 RAG도 원문을 제공하면 근거를 검색·설명할 수 있다. 이 보고서에는 그래프 제거 시 정답률이나 탐색 시간이 실제로 나빠진다는 시험이 없으므로 **모든 후보의 GraphRAG 필수성은 미입증**이다. 비교 시 같은 원문 세트·동일 질문으로 정확성, 누락, 조건 변경 결과, 출처 정확성 및 응답 시간까지 기록한다.

## 1. 보청기·스마트폰·부속품·국내 급여

### A. 문제와 시나리오
- 대상: 보청기를 쓰는 사람과 보호자. 입력: 정확한 보청기 모델·휴대폰/OS, 원하는 전화·TV 기능, 장애인 등록 여부와 구매 예정 업소. 출력: 확인된 연결 구성과 누락 조건, 급여 안내 근거. 진단이나 청력별 제품 추천은 제외한다.
- 예: Slim L-R 사용자가 TV 연결에 무엇이 필요한지 살피고, 국내 급여제품·등록업소 여부는 따로 확인한다. 단, 이 모델의 한국 급여 등록 여부는 **미확인**이다.
### B. 경쟁 및 ChatGPT
- [Phonak 호환성 검사기](https://www.phonak.com/en-uk/support/phone-compatibility)는 휴대폰·전화·스트리밍·앱 호환 정보를 설명하고, [Apple](https://support.apple.com/en-sg/106341)은 MFi 제품과 시스템 요구조건을 제시한다. [NHIS 급여 안내](https://www.nhis.or.kr/static/html/wbma/c/wbmac0206_1.html)는 등록장애인·등록업소 등의 조건을 제시한다. 개별 기능 중복이 명확하다. 타사·국내 급여까지 통합한 서비스 유무와 동일 입력의 실제 결과는 미확인.
- 동일 질문 ① “Phonak Slim L-R로 TV 소리를 들으려면 어떤 부속품과 추가 설치가 필요한가?” ② “이 모델이 국내 급여 대상이고 내 휴대폰에서도 앱을 쓸 수 있나? 확인 근거는?” ChatGPT 직접 응답 미검증. 일반 검색으로 각각 답할 가능성이 있고, 미등록·지역 차이를 허위로 채울 위험이 있다.
### C. 관계
- `사용자 → 보청기 모델 → TV Connector → TV`와 `모델 → Roger → 수신기 설치 조건`, `사용자 조건 → 급여 제도 → 등록 제품·업소`가 가설 경로다. 폰→OS→앱 호환 역시 명시 자료에 한정한다. TV 대신 전화, 해외 기종 대신 한국 기종으로 바꾸면 필요한 연결 조건이 달라질 수 있다.
- 웹 도구로 [제조사 Slim 매뉴얼](https://intl.phonak.com/en-lk/wp-content/uploads/sites/16/2024/02/PH_User_Guide_Slim_L_92x125_EN_V3.02_029-1128-02.pdf) PDF 51쪽을 열어 PDF상 13쪽(인쇄 24~25쪽)의 TV Connector, Roger 수신기 설치 필요 문장을 추출했다. [Phonak 주문서](https://www.phonak.com/content/dam/phonak/en/au/documents/forms/Phonak%20Lumity%20Audeo%20Slim%20Order%20Form.pdf.coredownload.inline.pdf)는 Slim Charger와 TV Connector를 명시한다. 실제 문서 간 모델·부속품 공통 항목은 보이나 국내 급여 제품과의 **정확한 동일 모델·등록 키 연결 미확인**이다. 다른 지역의 호환성을 한국 제품에 자동 이전하지 않는다.
### D. 데이터 및 권리
- 무료 공개 웹 문서 열람 및 PDF 웹 추출 확인. 로컬 다운로드, 독립 PDF/표 파싱, 모델별 한국 공단 급여 고시 원본·업소 실데이터, 제조사-공단 정확한 모델 연결, AS 정책·가격·유효일, 인용·가공·재배포·자동수집 조건은 미확인. 공단 기준은 [절차](https://www.nhis.or.kr/static/html/wbma/c/wbmac0206_2.html) 등과 함께 현행 검증 필요.
### E. MVP와 판단
- 2인 MVP 가정: 특정 제조사 모델 2~3개, 폰·TV·부속품의 공식 명시 관계만 수동 검수하고 출처 표시. 한국 급여 연결이 확보될 때만 추가. 상담 예약·구매·개인정보 수집 제외. 성공: 간선별 문서/페이지 정확, 지역·모델·시점 차이는 불명 처리, 조건 변경 결과를 수동 정답과 비교.
- **추가 검증**. 제품 관계 자체는 실재하지만 한국 지원제도와 제품의 연결, 기존 검사기 대비 실질 차별성, 권리와 다운로드가 검증되지 않았다. 통과·채택은 아직 불가.

## 2. 휠체어 이용자의 역·열차·이동 지원

### A. 문제
- 대상: 휠체어 사용자·동반자. 출발·도착역, 수동/전동, 시간 입력 → 후보 열차의 휠체어석과 역 이동 설비를 각각 표시하고 확인되지 않은 경로를 알린다. 시연은 정해진 두 역으로 축소.
### B. 경쟁 / 질의
- [코레일 모바일 안내](https://m.letskorail.com/mbt/m_guide.html)는 휠체어석·전동휠체어석 조회·예약을 제공한다. 국내외 지도와 접근성 길찾기의 같은 구간 실제 기능은 **미확인**이므로 없다고 주장할 수 없다.
- 질문 ① “서울역에서 부산역까지 전동휠체어석을 이용할 때 역 이동 시설과 확인할 조건은?” ② “출발역을 휠체어리프트만 있는 역으로 바꾸면 무엇이 달라지나?” ChatGPT 및 기존 앱 직접 결과 미검증.
### C. 관계
- `이용자 → 이동기기 → 역 시설 → 승강 동선 → 열차 좌석`. [서울시 파일데이터 설명](https://www.data.go.kr/data/15119423/fileData.do)은 역사별 엘리베이터·휠체어리프트 자료를, 코레일은 좌석 종류를 설명한다. 역 코드, 시설 방향·현장 동선, 열차/시간의 교차 연결 사례는 **미확인**이다. 단순 같은 역명이 연결·이용 가능성을 증명하지 않는다.
### D. 확보/조건
- 공식 자료 설명 무료 열람. [공공데이터 메타데이터 JSON](https://www.data.go.kr/catalog/15119423/fileData.json)은 CSV와 공공저작물 제1유형 출처표시를 명시한다. 이것은 **데이터셋 설명 JSON**이지 역사별 CSV 응답이 아니다. 실 CSV 다운로드·파싱, 자동 갱신 주기, 열차·동선·고장 정보 제공 및 결합 라이선스는 미확인. 2023-08-21 기준으로 표시되어 현재 시설 상태를 보장하지 않는다.
### E/F. MVP·판정
- 2역만 수동 검수하고 시설·좌석을 분리해 제시; 실제 고장·무장애 경로 보증 및 실시간 예약은 제외. 성공은 시설 존재·위치와 실제 이동 가능 경로를 혼동하지 않고 출처·기준일을 표시하는 것. **추가 검증**: 역간 연결과 실시간성, 지도/예약 경쟁 우위가 증명되지 않으면 탈락. 시설 존재만으로 이동 가능하다고 말하는 것은 실패다.

## 3. 프린터·소모품·구독·국가 변경

### A. 문제
- 대상: 해외 이동 또는 중고 프린터 구매자. 기종·구매국·현재국·구독 상태 → 구매 전 확인할 카트리지와 구독 제약을 표시. 지역 변경 시 선택지가 변하는 가설이다.
### B. 경쟁 / 질의
- [HP 앱과 카트리지 조회](https://www.hp.com/us-en/tech-takes/printing/how-to/how-to-find-hp-printer-ink-cartridge.html)는 모델로 호환 잉크 확인·구매 및 구독을 제공한다. [HP 지원](https://support.hp.com/ee-en/document/ish_1721989-1461843-16)은 지역 이동 시 재설정과 Instant Ink·HP+ 조건을 안내한다. 제안 기능의 상당 부분이 이미 있다. 국가 간 일괄 비교 기능은 직접 실행하지 않아 미확인.
- 질문 ① “해외에서 가져온 HP 프린터가 한국에서 새 카트리지를 쓸 수 있나?” ② “Instant Ink 가입 상태가 바뀌면 기존 카트리지 선택이 어떻게 달라지나?” ChatGPT 및 HP 앱 실제 결과 미검증.
### C/D. 데이터·관계
- `기종→카트리지→지역`, `프린터→구독→전용 카트리지→이용조건` 경로. [HP 설명서](https://h10032.www1.hp.com/ctg/Manual/c03773204.pdf) 인쇄 83쪽은 Instant Ink 미가입 프린터에서 해당 카트리지가 호환되지 않을 수 있음을 명시한다. [HP 공식 지원](https://support.hp.com/ee-en/document/ish_1721989-1461843-16)은 지역과 가입 조건을 명시한다. 그러나 특정 제품·한국 지역·현재 계약에 대한 **양쪽 원천의 동일 모델 연결은 미확인**. 모델 번호 없이 일괄 판정 불가.
- 공식 페이지와 PDF 검색 색인에서 본문 확인; 파일 로컬 다운로드·독립 파싱 미확인, 구매국/기종별 API 및 라이선스·상업적 재배포 조건 미확인.
### E/F. MVP·판정
- HP 한 모델·두 지역·구독 여부에 한정해 검수. 가격비교·임의 호환 제품 추천 제외. 실모델의 정확한 지역별 자료가 확보되고 HP 도구의 동일 질문과 차이가 입증될 때만 고려한다. 현재 **추가 검증**이나 핵심 중복으로 탈락 가능성이 높다. 고정 관계라 SQL이 충분할 가능성도 크다.

## 4. 유아 카시트·차량·설치 위치

### A/B. 문제 및 경쟁
- 부모가 차량 모델·연식과 아이 신체 조건을 입력하면 확인된 시트·차량·좌석 위치 및 설치 기준을 찾는 가설. [Cosatto 공식 FAQ](https://www.cosatto.com/a/faq)는 자사 제품의 차량 fit checker를 안내하며 [Child Car Seats](https://www.childcarseats.org.uk/choosing-using/child-car-seat-fitting-and-compatibility/)는 여러 제조사의 호환성 도구를 모은다. 다수 제조사 비교의 실제 범위는 미확인.
- 테스트 질문 ① “내 차에 이 카시트를 어느 좌석에 장착할 수 있나?” ② “차량이 바뀌면 같은 베이스를 계속 쓸 수 있나?” ChatGPT 실제 테스트 미검증.
### C/D. 데이터와 관계
- `차량·연식→장착 좌석→베이스→카시트→신장 제한`. 실제 조합의 공통 키·좌석 위치를 확인해야 한다. [Joie 호환 목록 PDF](https://dl.joiebaby.com/Instruction_Manual/GL/i-Spin-Safe/Joie-carseat-i-spin-safe-2025-fitting-list.pdf)는 검색 색인에 차량 차트가 있었으나 **실제 HTTP 요청에서 404**였고 다운로드 실패했다. 색인 텍스트만으로 현재 파일이 유효하다고 판단하지 않는다. 한국 차량/연식과 부품 문서의 실제 연결·이용 조건 미확인.
### E/F. MVP·판단
- 제조사 1개·차량 수종으로 축소, 매뉴얼과 설치 가능 위치를 수동 대조; 안전장착 인증이나 자동 적합 판정 제외. 자료·다중 출처 연결 및 차별성 부족으로 **추가 검증**. 제조사 도구와 같으면 탈락.

## 5. 여행 eSIM·기기·국가별 서비스

### A/B. 문제 및 경쟁
- 해외여행자가 기기 모델·구매국·잠금 상태·방문국을 입력해 공식 명시된 기기 지원 조건과 서비스 개통 전 확인사항을 본다. [GetMyUnlock 검사기](https://getmyunlock.com/esim-checker)는 기종 변형을 확인하고 잠금 문제를 안내한다. 통신사별·국가별 서비스 결과 비교는 미확인.
- 질문 ① “동남아에서 산 Pixel 3a에 이 여행 eSIM을 쓸 수 있나?” ② “휴대폰이 잠겨 있으면 어떤 선택지를 확인해야 하나?” ChatGPT 실험 미검증.
### C/D. 데이터
- `기종·판매지역→eSIM 기능→잠금 조건→통신사 서비스`. [Singtel 2025 목록 PDF](https://www.singtel.com/content/dam/singtel/personal/products-services/mobile/prepaid-plans/Terms%20%26%20Conditions/esim-Compatible%20List_Feb%2725.pdf) 2쪽에는 동남아에서 구매한 Pixel 3a는 지원하지 않을 수 있다는 예외가 있다. 웹 도구 PDF 텍스트 추출 성공. 이는 특정 기종의 가능성에 관한 예외이지 특정 요금제 이용 가능 증명이 아니다. 로컬 PDF, 요금제·국가·지역모델 간 실제 연결, 최신성·약관·재배포 조건 미확인.
### E/F. MVP·판단
- 통신사 1곳과 모델 5개로 축소해 공식 조건을 수동 대조. IMEI 저장·개통·가격 보장 제외. **추가 검증**; 기종 조건 필터만 남거나 업체 기능과 같으면 탈락. SQL·일반 검색 대비 우위 미실증.

## 6. 이어폰 분실 후 유닛·충전 케이스·교체

### A/B. 문제 및 경쟁
- 사용자: 유닛 또는 케이스를 분실한 사람. 모델번호와 남은 부품 → 호환 여부 확인·교체 경로. [Apple 모델 식별](https://support.apple.com/en-ie/109525), [AirPods 지원](https://support.apple.com/airpods), [불일치 안내](https://support.apple.com/en-ca/119613)는 세대 확인·Find My·교체 및 다른 세대 혼합 문제를 직접 안내한다.
- 질문 ① “A2031 유닛을 잃어버렸을 때 어떤 세대인가?” ② “케이스와 유닛 세대가 다르면 어떻게 확인하고 교체하나?” ChatGPT 실제 결과 미검증.
### C/D. 관계·자료
- `모델번호→세대→케이스→교체 서비스`. Apple 모델 목록은 A2031을 AirPods 2로 명시하고 불일치 안내는 다른 세대의 혼합을 다룬다. 정확한 단일 케이스/교체 부품 번호의 양쪽 교차 및 지역별 비용은 미확인. 공개 HTML 열람; API·다운로드·가공·재배포 조건 미확인.
### E/F. 판단
- 한 세대의 모델·교체 경로만 검증 가능하나 핵심 사용자 경험이 공식 지원에서 이미 제공된다. **탈락: 기존 기능 중복**. 관계 검색은 고정 조회로도 가능.

## 7. 무선 입력기기·수신기·컴퓨터

### A/B. 문제 및 경쟁
- 마우스와 키보드를 함께 쓰는 사람이 장치·수신기 종류를 입력해 결합 가능성과 페어링 방법을 확인. [Logitech](https://www.logitech.com/en-us/discover/a/setup-unifying-receiver)은 호환 장치 최대 6개와 앱을 통한 추가·관리 방법을 제공한다.
- 질문 ① “이 마우스와 키보드를 같은 수신기에 묶을 수 있나?” ② “Unifying 수신기를 바꾸면 두 장치를 어떻게 다시 연결하나?” 실제 ChatGPT 응답 미검증.
### C/D. 관계·자료
- `키보드→수신기←마우스`, `수신기→컴퓨터/관리 앱`. [공식 Unifying PDF](https://www.logitech.com/images/pdf/userguides/multi_connect_instructions.pdf)는 호환 기기와 공유 수신기를 설명한다. 특정 두 모델의 개별 매뉴얼과 같은 수신기 연결은 미확인. PDF 로컬 확보·추출 및 권리 미확인.
### E/F. 판단
- 제조사 하나만으로도 기존 앱이 같은 결합과 관리를 제공한다. **탈락: 핵심 기능 중복 및 그래프 필요성 부족 가능성**. 서로 다른 프로토콜을 임의로 호환 처리하지 않는다.

## 8. 전기차·충전 규격·충전소·경로

### A/B. 문제 및 경쟁
- 운전자가 차종과 경로를 입력해 쓸 수 있는 충전소와 대안을 선택한다. [PlugShare 경로 계획](https://help.plugshare.com/hc/en-us/articles/7387256318227-Trip-Planner-Complete-Guide-To-Planning-Your-First-Trip)은 차량 플러그 필터와 경로 재설정을 설명한다. [무공해차 통합누리집](https://ev.or.kr/nportal/evcarInfo/initEvcarChargePriceV2.do)은 사업자·충전소·로밍 요금 비교를 제공한다. 카드 혜택은 다루지 않는다.
- 질문 ① “내 충전 규격으로 갈 수 있는 경로상 충전소는?” ② “첫 충전소가 불가능하면 경로상 다른 곳은?” 실제 서비스·ChatGPT 질의 결과 미검증.
### C/D. 관계·자료
- `차종→커넥터→충전기→충전소→경로`. 공공 요금 페이지 무료 열람 확인, 특정 차종·충전기의 공식 실데이터 조인, API 호출·갱신·조건·라이선스 미확인. 커넥터 일치만으로 실제 충전·고장 여부를 단정하지 않는다.
### E/F. 판단
- 실시간 경로·플러그 선택이라는 핵심이 기존 제품에 이미 있다. **탈락: 핵심 기능 중복**. 고장 대안의 개별 제공 범위는 직접 테스트하지 않았다.

## 9. 알레르기·회수 식품·소비자 조치

### A/B. 문제 및 경쟁
- 특정 식품 알레르기가 있는 사람이 제품명·로트를 입력해 회수 여부와 반환 안내를 본다. [영국 정부 알레르기 알림](https://www.gov.uk/food-allergies/allergy-alerts)은 알레르겐별 무료 구독과 대상 제품·조치를 제공한다. 영국 한정 자료이며 한국 식품을 대표하지 않는다.
- 질문 ① “우유 알레르기가 있으면 해당 Pot Noodle을 어떻게 해야 하나?” ② “같은 제품이라도 다른 로트면 같은 회수 대상인가?” ChatGPT 직접 테스트 미검증.
### C/D. 관계·자료
- `알레르겐→회수 공고→제품→로트→환불 조치`. [FSA 공식 원문](https://alerts.food.gov.uk/news-alerts/alert/fsa-aa-43-2026)은 2026-10-02, Pot Noodle Piri Piri Chicken 90g, 로트 L6232PB796, 미표시 우유, 반환 안내를 명시한다. 한 문서 안의 실제 관계이며 두 출처 연결은 아니다. [FSA API 명세](https://data.food.gov.uk/food-alerts/ui/reference)는 알레르기/회수 필터와 예시 라이선스를 설명하나 JSON 샘플 호출은 실패했다. 로컬 데이터·세부 권리 및 국내 제품 연결 미확인.
### E/F. 판단
- 한 공고로 답이 나오고 공식 알림이 제품과 조치를 이미 제공한다. **탈락: 핵심 기능 중복 및 단일 문서 검색**. 목록에 없다고 안전하다고 판정하는 기능은 제외한다.

## 10. 개인 복지서비스·자격·중복 제한

### A/B. 문제 및 경쟁
- 개인이 생애 이벤트와 기존 수급내역에 따라 서비스 간 적용 조건과 제한을 확인하려는 문제. [복지멤버십](https://www.bokjiro.go.kr/ssis-tbu/twatza/wmAplyMng/selectWmJoinProcGdnc.do)은 결혼·출산·질병 등 변화에 따라 받을 수 있는 사업을 조사·안내한다. [정부24 혜택알리미](https://plus.gov.kr/portal/benefitV2/)도 맞춤 안내를 제공한다. 실제 중복·예외 설명 범위는 미확인.
- 질문 ① “출산 후 받을 수 있는 서비스 중 현재 수급 중인 지원과 함께 확인해야 할 제한은?” ② “가족 구성이나 수급 내역이 바뀌면 어떤 조건을 다시 확인해야 하나?” 일반 ChatGPT와 기존 서비스 직접 실행 미검증.
### C/D. 관계·자료
- `사용자 조건→서비스→자격 조항→다른 서비스와 제한` 가설. 공식 복지로 페이지의 맞춤 안내·가입 조건은 확인했지만 **두 실제 서비스 사이 명시적 상호 제한 관계 및 현행 원문**은 미확인. 이름·목적이 비슷하다고 중복 수급 금지라고 추론하지 않는다. API·파일·독립 파싱·라이선스·개인정보 처리 조건 미확인.
### E/F. 판단
- 지원제도 2건과 제한 조항 1건이 먼저 필요하다. 개인정보 입력 없이 가상 사례만 시연하고 수급 확정 제외. **추가 검증**; 기존 맞춤 안내와 실질 차이가 없거나 명시적 연결을 구하지 못하면 탈락. 과거 기업 지원사업을 개인 복지로 이름만 바꾸어 차별성을 가정하지 않는다.

1. 해당 공식 자료의 실제 파일 또는 API 샘플을 적법하게 확보하고, 주요 필드·페이지를 별도 도구로 추출한다. 발행일, 모델, 지역, 인증과 호출량 및 상업적 가공·인용·재배포 조건을 확인한다.
2. 보청기는 제조사 제품명과 국내 급여 고시의 **정확한 동일 모델**을 양쪽에서 1건 이상 찾고 등록업소·시점까지 확인한다. 휠체어는 역 식별자·시설 위치·열차 좌석 간 실사례를 찾는다. 프린터는 특정 제품과 지역·구독의 실제 문서 쌍을 찾는다. 미확인 링크를 억지로 만들지 않는다.
3. 각 후보에서 위 두 질문을 ChatGPT와 기존 서비스에 동일 입력으로 실제 수행하고 응답 원문·시각·근거를 기록한다. 원문 세트를 고정해 RAG와 SQL을 비교하고, 그래프가 더 정확한 다단계 경로·조건 변경 결과를 제공하는지 검증한다. 반복 가능한 사용자 가치가 없으면 중단한다.
4. 답·간선·출처 페이지의 수동 정답셋, 자료 갱신 시점과 불명 처리를 정하고 Streamlit 화면 1개로 2인 구현 시간을 산정한다. 이는 개발 지시가 아닌 후속 검증안이며 아직 미실시다.

**결론:** 사용자에게 직관적인 문제는 찾았지만, 현재 기존 서비스와의 차별성, 공식 원본 확보·활용 권한, 서로 다른 자료 사이의 연결, GraphRAG가 꼭 필요한 가치가 모두 증명된 후보는 없다. 따라서 **상위 3개 추천 및 1순위 선정은 보류**한다. 보청기는 다단계 제품 관계의 구체 자료가 있어 추가 조사할 만하지만 국내 급여·A/S 연결과 경쟁 우위를 증명하기 전에는 채택할 수 없다.
