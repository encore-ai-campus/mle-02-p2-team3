## 1. 결론

**확정 추천: 적합한 주제 미발견.** 10개를 비교했으나 사용자께서 요구한 후보별 실문서 두 건 이상의 교차 연결, 경쟁 제품의 기능별 검증, ChatGPT 실제 비교를 충족한 주제는 없다. 특히 겉보기에는 유망한 FDA 기기 선행제품 그래프조차 기존 서비스가 이미 계보와 출처를 제공한다. 차별성은 실측되지 않았다. 아래 3개는 **추가 검증 우선순위일 뿐 TOP 3 추천 확정이 아니다.**

1. FDA 510(k) 선행제품 관계와 문서 비교: 명시적 K번호로 연결하기 쉽지만 유사 경쟁 서비스가 강력하다.
2. 공공조달 제재 사유와 법령 근거: 실제 처분 문서에 법령과 인증 취소가 나타나나 과거 처분의 현재 효력을 추정하면 안 된다.
3. EPA 오염 부지와 정화 결정의 변화: 사용자의 환경 정보 추적 수요가 명확하지만 같은 부지의 원문 두 건과 차별성을 아직 실증하지 못했다.

## 5. GraphRAG 적합성과 문서 연결 검증

아래 경로는 **질문 설계**다. 실증된 간선은 별도로 표시하며 나머지 경로는 데이터에 실제로 있다는 뜻이 아니다. SQL 재귀 쿼리로도 각 경로를 구현할 수 있다. Neo4j의 장점은 여러 유형과 길이의 경로 조회 및 근거 간선 표현이고, 일반 RAG는 문서 근거 검색에 유용하나 다중 경로의 누락·방향 검증을 별도 구현해야 한다. 이것은 사용자 차별성의 증명이 아니다. 공통 MVP는 해당 경로 하나를 정형 조회하고 각 간선의 원문 위치를 보여주는 것이다.

## 6. 데이터 확보·권리·수작업

위 링크의 FDA PDF 두 건, 조달 공고, 법령 본문, 공공 안내 및 저장소 텍스트는 공개 열람했다. PDF를 로컬로 다운로드해 바이너리 무결성·추출 품질을 확인하지는 않았다. 온라인 접근과 실제 파일 다운로드 가능성은 구분한다. 두 교차문서 사례가 확인된 후보는 **없다**. API 승인 없이 데모하는 조건은 고정된 공개 원문을 수동 수집하는 방식으로 가정한다. 공공 API는 키·호출 제한을 확인해야 하며, [openFDA 510(k)](https://open.fda.gov/apis/device/510k/how-to-use-the-endpoint/)는 시험·사용에 키가 필수는 아니라고 명시한다.

## 7. 추가 검증 우선순위 3개: MVP와 중단 조건

### 1순위 후보: FDA 510(k) 선행제품 출처 추적

규제 업무 조사자가 공개 신청서의 선행제품을 읽고, 각 주장에 해당하는 PDF 페이지를 따라가는 도구다. `신청서 → 대상 기기 → 선행 기기 → 선행 신청서`가 구조이며 K번호가 문서 간 연결 키다. 확인된 K200321→K070722 링크는 두 원문에 근거한다. 단, 이는 **단 하나의 사례**이고 여러 세대의 선행 관계가 실증된 것은 아니다. [Imperial 대시보드](https://predicates.app/)가 이미 네트워크와 출처를 제공하므로 단순 그래프는 독창성이 없다.

3일 범위 가정: 첫날 한 제품군 PDF 10~20개 수집·수작업 간선 검증, 둘째 날 Neo4j 적재와 정형 경로 조회, 셋째 날 Streamlit 질문 2개·원문 링크와 페이지·발표 검증. 외부 서비스 회원가입 없이 고정 문서로 시연한다. PDF에서 선행 기기와 reference 기기를 혼동하거나 K번호를 잘못 추출할 위험이 있다. **착수 전** 두 번째 실제 문서 쌍과 연속된 2개 선행 간선, 경쟁 제품과 동일 질문을 확보해야 한다. ChatGPT 비교는 동일한 문서 세트와 질문을 제공해 간선·근거 페이지 정답률과 누락을 비교한다. 기존 대시보드가 같은 범위를 해결하거나 차이가 입증되지 않으면 중단한다.

### 2순위 후보: 조달 처분의 사유와 근거 추적

조달 담당자가 특정 과거 처분에서 인증·계약·법적 근거가 어떻게 연결되는지 확인한다. 구조는 `업체 → 처분 → 사유 → 취소된 인증`, 별도 간선은 `처분 → 근거조문`이다. [2022년 홈워터 공고](https://www.pps.go.kr/kor/bbs/view.do?bbsSn=2206280006&key=00324)는 이 관계를 하나의 문서에서 직접 보여준다. 따라서 현재 사례만으로는 GraphRAG보다 검색·표가 충분할 수 있다. MVP는 5건의 과거 공개 공고와 해당 시행 당시 법 조문을 검수하고 기간·출처를 표시하는 단일 조회다. **조건:** 실제 처분별 다른 문서 연결 2건을 확인하고 나라장터 기존 기능과 비교해야 한다. 제재의 현재 효력이나 낙찰 가능성은 판단하지 않는다. ChatGPT가 같은 공고와 조문을 빠짐없이 연결하면 중단한다.

### 3순위 후보: EPA 부지의 정화 결정 이력

지역 주민이나 환경 조사자가 한 부지의 최초 결정과 후속 변경을 추적하는 도구다. `부지 → 최초 결정 → 정화방법`, `후속 결정 → 변경 대상`을 문서별 페이지에 연결한다. EPA는 [문서 검색](https://www.epa.gov/superfund/search-superfund-documents)과 부지 ID를 제공한다. MVP는 부지 한두 곳의 결정·변경 문서 각 두 개를 확보했을 때만 타임라인과 비교 경로를 구성한다. 영어 문서 길이와 후속 결정의 명시적 변경 대상 검증이 위험이다. 현재 실제 쌍이 확인되지 않아 3일 견적의 근거가 부족하다. ChatGPT와 EPA 검색에서 동일 부지·동일 문서로 변경 전후와 근거를 비교한다.

## 8. 보류·탈락 이유와 최종 권고

취약점과 라이선스는 이미 전용 스캐너가 의존 관계와 위험을 다룬다. 법령은 공식 3단 비교가 핵심을 상당 부분 제공한다. FDA 리콜은 공식 검색 자체가 510(k)번호를 지원한다. 지원사업은 사업 간 상호 제한의 실문서 관계가 입증되지 않았다. DART PF는 높은 도메인 가치와 달리 AI 공시 분석 경쟁이 존재하고, 현장·조합 식별과 교차 공시가 아직 증명되지 않아 3일 계획을 확정할 수 없다. 기업 계열사 역시 관계 원문 결합과 서비스 차이가 확인되지 않았다.

**최종 권고는 주제 확정 보류**다. 기존 카드 주제보다 적합하다고 입증된 주제는 아직 없다. 가장 먼저 FDA 후보의 실제 2번째 문서 연결과 기존 계보 도구·ChatGPT 비교를 수행하되, 경쟁 도구 대비 실질적 차이와 3일 내 완성 가능성을 입증하지 못하면 채택하지 않는다. 이 보고서는 10개 후보의 경쟁·원문 실증을 모두 완료한 결과가 아니라, 확인된 사실과 남은 공백을 명시한 예비 조사다.
