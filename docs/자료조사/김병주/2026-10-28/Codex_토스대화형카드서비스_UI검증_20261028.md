# 토스 대화형 카드 서비스 공개 UI 검증

- 조사일: 2026-10-28 (한국 시간)
- 방법: @Browser 내장 브라우저에서 로그인 없이 공개 페이지를 렌더링하고 메뉴 및 필터를 직접 클릭해 확인. Windows 외부 Chrome은 사용하지 않음.

## 결론

확인한 공개 카드라운지 화면은 카드 목록, 혜택 카테고리, 필터 및 비교함 중심이다. 확인한 화면과 이동 경로에서 자유로운 자연어 질문을 입력하는 대화형 진입점은 발견하지 못했다. 따라서 AI의 자연어 답변 및 이전 조건을 이어가는 연속 대화는 확인하지 못했다. 이는 조사한 공개 UI의 관찰 결과이며 토스 전체 또는 로그인 후 앱에 해당 기능이 없다는 증거는 아니다.

## 방문 및 화면 증거

1. https://card-lounge.toss.im/ — 메인 화면에서 상단 카드사·랭킹·카드 찾기, 전체 필터, 통신비 등 혜택 카테고리와 나이대별·혜택별·카드사별 인기 카드 목록을 확인했다. ‘카드 찾기’를 클릭하여 검색 결과로 이동했다.
2. https://card-lounge.toss.im/search — 2026. 10. 28 기준 1,737개 카드와 여행·생활비·통신비 등의 카테고리, 카드사·연회비·전월실적·혜택 유형 필터 및 카드별 연회비와 실적을 표시했다. ‘필터’를 클릭하면 카드사, 연회비 구간, 전월 실적 구간, 할인형·적립형·마일리지형을 선택하고 결과를 보는 창이 나타났다. 이는 정해진 조건을 선택하는 필터이며 AI 대화창이 아니다. 화면에서 카드명 검색 입력창도 확인하지 못했다.
3. https://card-lounge.toss.im/compare-card-list — 빈 비교함에 ‘카드를 담아서 비교해보세요’와 ‘필터 검색 하러가기’ 버튼이 표시됐다. 버튼을 클릭했다. 카드가 담긴 비교 결과는 검증하지 않았다. 질문 입력창은 발견하지 못했다.
4. https://toss.im/service/card — 공개 소개 화면에서 ‘소비 내역 분석해서 내게 가장 유리한 카드 찾기’, 실제 소비 데이터 기반 추천, 지난 한 달 사용처 분석, 인기순·카드사별·혜택별 비교를 설명한다. 이는 서비스 소개 문구이며 AI 대화 기능의 작동 증거가 아니다. 소개 화면에 대화 입력창은 발견하지 못했다.

위 URL과 표시 문구, 화면 이동 경로는 재방문하여 확인할 수 있는 화면 증거다. 화면은 시점, 기기 및 접속 환경에 따라 달라질 수 있다. 별도 스크린샷 파일은 저장하지 않았다.

## 질문별 검증

| 질문 | 확인 결과 |
|---|---|
| A. 다음 달부터 OTT와 통신비 자동납부를 시작하려고 하는데 어떤 카드가 좋을까? | 해당 자유 질문을 입력할 대화형 화면을 발견하지 못해 입력·답변을 시험하지 못했다. 통신비 카테고리는 보았지만 미래 계획을 이해하는 추천으로 볼 수 없다. |
| B. 그중 체크카드만 알려줘. | 앞선 대화와 연결할 대화창을 발견하지 못해 시험하지 못했다. 필터 창에서 체크카드 선택은 확인하지 못했다. |
| C. 간편결제로 결제하면 혜택이 제외되는 카드는? | 대화형 질문과 AI 답변을 시험하지 못했다. 개별 카드 약관의 모든 조건을 검토하지 않았다. |
| D. 직접결제로 바꾸면 혜택 조건이 달라져? | 이전 질문을 이어받는 대화 기능을 발견하지 못해 시험하지 못했다. |

일반 검색창에 질문 A~D를 억지로 입력하지 않았다. 자연어 입력 가능 여부, AI 답변 품질, 문맥 유지 능력은 모두 미확인이다.

## 범위와 한계

로그인, 회원가입, 카드 발급은 하지 않았다. 토스 앱의 로그인 후 화면, 개인 소비 데이터 연결, 개인화 추천의 실제 동작, 다른 기기·계정·실험군, 사이트의 모든 카드 상세 및 숨겨진 진입점은 확인하지 않았다. 공개 소개의 소비내역 기반 추천은 확인했으나 앱에서의 자연어 대화 지원 여부는 판단할 수 없다. 비교함은 빈 상태만 확인했다. 이 보고서는 지정된 공개 화면에서 직접 관찰한 기능과 한계를 기록한다.
