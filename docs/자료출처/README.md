# 자료 출처 기록

저장소에 외부에서 전달된 명세나 자료를 넣을 때 원본의 출처, 사용 범위, 저장소에서 한 일을 함께 기록한다. 자료마다 이 문서의 양식을 복사해 기록 파일을 만들고, 아래 색인에도 한 줄을 추가한다. 확인하지 않은 사실은 추측하지 않는다.

## 기록 규칙

- 모르는 값은 비워 두지 말고 `확인 필요`라고 쓴다. 전달자, 전달일, 전달 형태와 경로를 추정하지 않는다.
- 전달자에는 이름 또는 역할만 기록한다. 개인 연락처 등 개인정보는 기록하지 않는다.
- 비밀정보(예: `.env`, 접속 정보)와 PDF 전체 원문은 기록 파일에 넣지 않는다. 원본 보관 위치에는 저장소 밖의 경로만 적고, 원문 내용을 복사하지 않는다.
- 원본 해시는 SHA-256으로 확인한 값만 적는다. 확인하지 못했으면 `확인 필요`라고 쓴다.
- 출처가 나중에 확인되면 확인된 해당 항목만 고치고, 기록자와 기록일도 갱신한다. 다른 미확인 항목을 추정으로 채우지 않는다.
- 사용 범위·제한은 공개 가능 여부와 재배포 제한을 기록한다. 모르면 `확인 필요`로 둔다.

## 자료별 기록 양식

아래 블록을 자료마다 복사한다.

| 항목 | 기록 |
|---|---|
| 자료 이름 | 확인 필요 |
| 저장소 안 위치 | 확인 필요 |
| 원본 형태(문서/메일/메신저/구두 등) | 확인 필요 |
| 전달자(이름 또는 역할, 연락처 제외) | 확인 필요 |
| 전달일 | 확인 필요 |
| 전달 경로 | 확인 필요 |
| 원본 보관 위치(저장소 밖 경로만) | 확인 필요 |
| 원본 해시(SHA-256) | 확인 필요 |
| 사용 범위·제한(공개 가능 여부, 재배포 제한) | 확인 필요 |
| 우리가 바꾼 점(옮긴 사람/날짜/변환 방법) | 확인 필요 |
| 검증 상태 | 확인 필요 |
| 기록자와 기록일 | 확인 필요 |
| 확인 필요 항목 | 확인 필요 |

## 출처 확인 후 갱신하기

사용자는 확인된 출처 정보에 해당하는 셀만 수정하고, 확인되지 않은 셀은 `확인 필요`로 둔다. 기록자와 기록일을 확인 시점에 맞게 갱신한 다음 색인 행의 출처 상태를 `확인됨`으로 바꾼다(필수 출처 정보가 여전히 미확인이라면 `확인 필요`를 유지한다). 변경한 셀과 근거를 팀에 알리고, 두 README를 커밋하도록 사용자에게 요청한다. 작업자는 이 변경에 대해 `git add`, 커밋 등 Git 쓰기를 하지 않는다.
