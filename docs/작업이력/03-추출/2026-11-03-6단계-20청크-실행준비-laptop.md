- `.env`, DB 접속 정보, API 키 값은 열거나 출력하지 않았다.

## 실행 결과

- 사전 추정 명령은 성공했고, 입력 크기는 67,234 tokens로 나왔다.
- 사용자가 `.env` 확인을 허용해 해당 파일의 값을 화면에 출력하지 않고 `OPENAI_API_KEY`만 실행 프로세스 환경에 전달했다.
- 첫 실행은 모듈 검색 경로 설정 누락으로 호출 전 중단됐다. 재실행에서는 결과 폴더 쓰기 권한으로 `~/pilot_work/out8` 저장이 거부되어, 허용된 `/tmp/pilot_work/out8` 경로를 사용했다.
- 20개가 모두 시도됐지만 20개 모두 `llm_call_failure`로 끝났다. 실패 메타데이터는 `OpenAIConnectionError` 계열과 DNS `gaierror`이며 HTTP 상태 코드가 없다. 따라서 성공 응답/추출 항목은 0개이고, 호출이 OpenAI API에 도달하지 못한 연결 단계 실패로 확인됐다.
- 실제 토큰 사용량·모델 응답은 없고, 이 실패 결과에는 입력/출력 사용량이 기록되지 않았다. DNS 연결 실패 기록만으로 청구 여부를 단정할 수 없으므로 OpenAI 사용량 화면에서 확인이 필요하다.
