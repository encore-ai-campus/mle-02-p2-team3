## 직접 확인한 사실

- 저장소의 `full_run_report.py`는 저장된 실행 결과를 청크·위치·스키마·항목 그룹·길이 구간·빈 결과 표 밀도별 수치로 집계하며, JSON 본문에 PDF/청크/인용문 텍스트를 기록하지 않는다.

```bash
UV_CACHE_DIR=/tmp/uv-cache PYTHONPATH=src:src/card_benefit uv run --locked --no-sync python -m payment_card.file_pipeline.extraction.full_run_report --result-dir ~/pilot_work/full_hana/results --chunk-dir ~/pilot_work/chunks/hana --output-json /tmp/full-hana-report.json
```

## 해석 및 미완료

- 짧은 청크의 빈 결과는 정상일 가능성, 긴 청크에서 빈 결과율이 다시 오른 것은 표 읽기 한계일 가능성으로 본다. 둘 다 **추정**이며 원문을 열어 판정하지 않았다.
- 결과 파일의 존재·mtime·집계값을 직접 확인하지 못했다. 필요하면 위 명령을 재실행한다. 청크 본문이나 PDF 원문은 이력에 싣지 않는다.
