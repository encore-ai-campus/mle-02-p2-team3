## 직접 확인한 사실과 추정

- **직접 확인:** out8 결과 JSON은 50개이며, extraction 존재 46개, 미존재 4개다. `empty_result`는 19건이고 실패 코드 합계는 위 표와 같다.
- **직접 확인:** out8의 네 그룹 항목은 합계 527개, 근거 evidence는 576개다. 결과 JSON에 있는 evidence 중 location이 있는 것은 480개, 없는 것은 96개다. 실패 코드의 위치 이벤트 수와 evidence 수는 별도 집계이며 서로 같은 분모가 아니다.
- **직접 확인:** 스키마 실패는 4건이다. 해당 실패 메시지에서 `Condition.kind=CHANNEL`은 확인되지 않았다.*
- **직접 확인:** `pilot_ids20.json`과 실제 결과에서 비교 가능한 교집합은 4개다. 해당 교집합의 전체 항목 합계 차이는 -1개다.
- **추정:** 빈 결과는 짧은 청크에 더 많이 나타난 것으로 보인다. 이는 길이와 표 밀도의 동시 상관 집계일 뿐, 원인이나 추출 적합성을 판정하지 않는다.
- **추정:** 앞선 20청크와 50청크의 전체 항목 평균·합계는 표본 크기와 실행 조건이 달라 직접적인 성능 우열을 뜻하지 않는다.

## 하지 않은 것과 남은 위험

- 비용과 소요시간은 대시보드 값 미수신이며, summary 파일은 95개로 50개 결과와 매칭되지 않아 결과별 검토 필요·요약 지표를 검증하지 못했다.
- `Condition.kind=CHANNEL` 0건은 로컬 결과의 schema failure 메시지에서 해당 경로/값을 찾지 못한 결과다. 별도 스키마 전수 검증 출력이 아니다. `부분 후보`는 실패 코드와 항목 동시 존재로 계산했으며, summary의 partial 값과 같은 정의인지 확인하지 못했다.
- 사람의 원문 대조 정확성 검증은 하지 않았다. 인용문 위치 존재 여부는 인용의 의미 정확성을 뜻하지 않는다.
- 표 밀도는 텍스트 기반 휴리스틱이며 PDF 표 판정이 아니다. 선택목록과 결과 양쪽에 있는 청크가 4개라 교집합 비교가 제한적이다.
