## 리뷰와 수정

별도 Claude 리뷰어가 지적하고 Codex가 수정한 사항으로 전달받았다. 저장소의 변경 파일·diff는 확인했으나 코드 내용은 이력에 포함하지 않는다.

- `item_loss_report.py`: `_category` 인자 순서 오류로 fuzzy 분류에서 분류 조건이 무시되던 문제, 실패/미처리 청크의 항목이 사라진 것으로 집계되던 문제, 기준 실행 1개일 때 once-only를 정의할 수 없던 문제, 이름 없는 limit/target/condition 키 충돌을 고쳤다.
- `empty_review.py`: tally 헤더 판정, 메모 체크 오인식, 고정된 “8개 중” 문구, 열람 파일 덮어쓰기 보호, 파일명 치환 문제를 보완했다.
- 테스트 보강: CLI JSON 출력, 동점 top-N, `.ipynb_checkpoints` 제외, 최소 노트북 수를 확인하도록 했다.
