# 7단계 자동 점검 숫자 기준과 근거 표시

- PC: laptop
- 상태: 커밋 전
- 오탐 원인 재현: 지정 청크 `ec1a4aa0419d6591-p0014-c01`, `95faf9114321349c-p0012-c01`을 직접 확인했다. 기존 점검은 `benefits.name`, `conditions.text` 같은 요약 라벨과 분류값까지 원문 부분 문자열로 검사했고, 정수는 일부 고정 한국어 표기만 지원했다. 그 결과 `400000`과 띄어 쓴 만 단위 표기, 혼합 만·천 단위 표기가 서로 대응하지 않았다. 숫자 부분 문자열 검사는 `1`과 `1만원` 경계도 구분하지 못했다.
- 수정: `schema.py`의 수치 필드(`benefits.rate/amount`, `conditions.min_amount`, `limits.amount`)만 점검한다. 콤마·공백, 한국어 단위, 원·횟수·기간·퍼센트, 소수와 혼합 단위 숫자를 환산해 양방향으로 비교한다. 자동 후보는 `숫자 확인 필요` 또는 `숫자 이상 없음`으로 표시한다.
- 열람 파일: 상단에 읽는 방법 5단계와 판정 의미를 두고, 빈 항목은 틀림이 아님을 명시했다. 요약 항목별 evidence 최대 2개와 원문 줄 번호 또는 위치 미확인 표기를 추가했다. Relation은 evidence 한 줄만 표시한다.
- 한계: 자동 점검은 힌트다. 표기 변환을 모두 알아내지 못할 수 있다. 사람은 원문에서 빠진 혜택만 확인한다.
- 확인: 합성 회귀 테스트와 표준 테스트 명령 통과(196 passed). 실제 판정표와 열람 파일은 변경하지 않았다.
