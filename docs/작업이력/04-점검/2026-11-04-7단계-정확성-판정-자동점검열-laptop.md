# 7단계 정확성 판정 자동 점검 열

- PC: laptop
- 상태: 구현 및 합성 테스트 확인, 커밋 전
- 직접 확인: `accuracy_review.py`에 빈 항목/원문 값 대조와 자동 후보를 추가하고 `--tag v2` 출력 경로를 분리했다. 새·기존 판정표 집계, 지정 30개·시드 재현성, 노트북의 합성 예시를 확인했다.
- 추정: 자동 미발견 표시는 값 불일치 가능성을 가려내는 보조 후보다. 부분 문자열 일치는 값의 의미가 맞다는 보장이 없다.
- 판정 의미 재정의 이유: 기존 한 칸으로 값 불일치, 빈 항목, 혜택 누락을 동시에 판단하기 어려워, 기계가 객관적인 값 존재·빈 항목을 따로 집계하고 사람이 혜택 누락만 확인하도록 했다. 틀림은 추출값이 원문에 없거나 다른 값, 일부 누락은 원문 혜택이 더 있으나 추출되지 않음, 맞음은 둘 다 아님이다.
- 한계: 글자 일치 중심으로 검사하며 표기 변환은 제한적으로만 지원한다. `30,000원`↔`3만원` 외 표기 변환은 놓칠 수 있고, 자동 검사는 누락 혜택을 찾지 못한다.
- 사람은 빠진 혜택만 확인한다. 빈 항목은 정밀도와 별도 지표다.
- 직접 확인: 요청한 하나카드 `prepare --size 30 --seed 20261104 --tag v2` 실행은 입력 로드 후 `/home/lee/pilot_work/review/accuracy_view_v2` 생성에서 읽기 전용 파일시스템 오류로 중단됐다. 판정표는 생성되지 않아 후보 분포와 빈 항목 총계는 미확인이다.
- 재실행 명령: `UV_CACHE_DIR=/tmp/uv-cache PYTHONPATH=src:src/card_benefit uv run --locked --no-sync python -m payment_card.file_pipeline.extraction.accuracy_review prepare --result-dir ~/pilot_work/full_hana --chunk-dir ~/pilot_work/chunks/hana --output-dir ~/pilot_work/review --size 30 --seed 20261104 --tag v2`
