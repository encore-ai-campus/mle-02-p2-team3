# 10단계 Neo4j 노트북 로컬 전용 정정

- 날짜: 2026-11-04
- PC: laptop
- 상태: 커밋 전

## 발견

- `.env`의 `NEO4J_URI`가 로컬 컨테이너가 아니라 원격 Aura를 가리키고, 해당 DB에서 팀원 `dp_*` 그래프 라벨 15개가 확인된 사실을 사용자에게서 전달받았다.
- 기존 안전장치 `ALLOW_REMOTE=False`가 원격 쓰기를 막았고, 데이터가 쓰이지 않았다.
- 두 샘플 파일의 정적 검사는 생성기 `FP_HAS_EVIDENCE` 근거 연결 관계를 허용 관계 집합에 포함하지 않았고, 타입 있는 관계까지 유형 없는 관계로 오탐했다.

## 수정

- 연결 기본값을 로컬 `bolt://localhost:7687`, 사용자 `neo4j`, 실행 시 `getpass` 비밀번호 입력으로 바꿨다. 비밀번호가 비어 있으면 인증 없이 연결을 시도한다.
- 기본 경로에서는 `.env`를 로드하지 않는다. `USE_ENV_REMOTE=True` 선택 시에만 원격 환경 변수를 읽고, 원격 연결은 읽기만 허용하며 쓰기·삭제 경로를 차단한다.
- 연결 후 `dp_` 라벨이 발견되면 경고하고 계속할 수 있게 했다. 적재 정적 검사는 `Fp` 라벨과 생성기 관계만 허용한다.
- 관계 타입 판별 정규식을 고쳐 타입 없는 `-[r]->`, `-[]->` 형태만 차단하고 `FP_HAS_EVIDENCE`를 허용했다.
- README 연결 안내와 노트북 테스트를 로컬 전용 정책에 맞췄다.

## 한계

- 로컬 `graphrag-neo4j` 컨테이너에 실제 접속하거나 DB 상태를 확인하지 않았다. 노트북 코드는 연결만 수행하도록 작성했으며 Codex는 실행하지 않았다.
- 샘플 Cypher 검사는 Neo4j 연결 없이 파이썬 정적 검사 로직으로만 확인했다.
