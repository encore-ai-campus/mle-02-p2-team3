# 11단계 챗봇 래퍼·시험 하네스

PC: laptop  
상태: 구현·가짜 데이터 검증 완료, 커밋 전

## 설계

- 팀 `graphrag_chatbot`을 수정하지 않고 `fp_chat` 뷰를 선택 적용하는 래퍼와 Streamlit 진입점을 추가했다.
- 검색은 질문의 2자 이상 한글·영문·숫자 토큰으로 최대 300개를 먼저 찾고, 부족분은 Card·Benefit으로 채워 최대 500개로 제한한다. 입력 문자열은 파라미터 바인딩하며 스키마 식별자를 검증한다.
- 그래프 CSV에서 6종 평가 질문을 재현 가능하게 생성하고, 기본 드라이런 및 선택 실행 평가기를 추가했다. 산출물은 `/tmp`에만 둔다.
- 노트북 예제는 합성 CSV만 사용하며 DB·LLM에 연결하지 않는다.

## 보호 범위 확인

`git diff -- src/graphrag_chatbot src/common` 결과는 비어 있다. 두 경로는 읽기 전용으로 유지했다. `graph/chat_views.sql`도 읽기만 했다.

## 확인하지 못한 사항과 한계

- 실제 DB·LLM 실행은 금지된 범위라 확인하지 않았다.
- 로컬 `/tmp/fp-check-hana`, `/tmp/fp-check-woori` CSV가 있을 때의 실제 유형별 질문 수는 확인하지 않았다.
- `DB_URL` 권한, 실제 테이블/뷰 존재 및 질의 성능은 사용자 환경에서 확인해야 한다.
- 사용자 승인 필요 항목: `fp_chat` 뷰 적용 및 실행 평가에서 실제 DB·Anthropic API 호출 허용 여부.
- 문서와 테스트에는 PDF 원문이나 인용문 본문을 포함하지 않았다.
