## 적재·연결·시험 순서

1. 사용자 SQL Editor 실행 결과로 마이그레이션 검증 완료: 잔여 `pf_` 객체 0행, `fp_edges`, `fp_evidence`, `fp_load_runs`, `fp_nodes` RLS 모두 `true`. 하나카드 적재는 아직 실행하지 않았다.
2. 하나카드를 `public.fp_*`에 적재: 드라이런 → 사용자 승인 → 실행. `FP_DATABASE_URL`은 사용자가 설정한다.
3. `chat_views.sql`을 실행한다.
4. GRAPH 스키마 `fp_chat`으로 챗봇을 실행한다. 사용자가 `DB_URL`, `ANTHROPIC_API_KEY`를 설정한다.
5. 질문 5개로 확인한 뒤 60문항 평가를 한다.
