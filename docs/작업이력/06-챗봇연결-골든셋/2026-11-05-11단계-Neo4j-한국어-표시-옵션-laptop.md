# 11단계 Neo4j 한국어 표시 옵션

PC: laptop

## 목적

Neo4j Browser에서 Fp 지식그래프의 노드·관계·enum 표시를 한국어로 읽을 수 있도록 내보내기 옵션, 사후 적용 쿼리, GraSS 스타일 생성을 추가했다. 기본 스키마와 영어 속성은 유지한다.

## 옵션 및 매핑

- `--lang en|ko`: 기본은 `en`; `ko`에서만 표시용 속성 추가
- `--grass-out /tmp/스타일.grass`: Browser 스타일 파일 생성
- `--backfill-ko-out /tmp/backfill.cypher`: 이미 적재된 Fp 그래프에 표시 속성을 설정하는 쿼리 생성

| 구분 | 값 | 표시 |
|---|---|---|
| 노드 | Issuer, Card, Benefit, Condition, Limit, Target, Evidence | 발급사, 카드, 혜택, 조건, 한도, 적용 대상, 근거 |
| 관계 | OFFERS, HAS_CONDITION, HAS_LIMIT, APPLIES_TO, EXCLUDES, MUTUALLY_EXCLUSIVE, HAS_EVIDENCE | 제공, 조건 있음, 한도 있음, 적용 대상, 제외 대상, 같이 못 받음, 근거 있음 |
| Benefit.method | DISCOUNT, CASHBACK, POINT | 할인, 캐시백, 포인트 |
| Condition.kind | SPEND_REQ, EXCLUDE, USAGE, PAYMENT, MERCHANT, OTHER | 이용 실적, 제외, 이용 조건, 결제 수단, 가맹점, 기타 |
| Limit.period | TXN, DAY, MONTH, YEAR, UNKNOWN | 건별, 일별, 월별, 연간, 미상 |
| Target.kind | MERCHANT, INDUSTRY, CHANNEL, SERVICE, OTHER | 가맹점, 업종, 채널, 서비스, 기타 |

미등록 enum 값은 원래 값을 표시 속성에 복사하고 stderr 경고 집계에 포함한다. `caption_ko`는 `[노드 종류] 기존 캡션` 형식이며 80자로 자른다.

## 사용 방법

하나 샘플은 카드 목록에서 확인한 `card:hana:101206011022473`, 우리 샘플은 `card:woori:243838`을 사용했다. 카드별 혜택 1개 제한으로 생성했다.

내보내기 예: `uv run --locked --no-sync python -m payment_card.file_pipeline.graph.cypher_export --csv-dir /tmp/fp-check-hana --card-id card:hana:101206011022473 --max-benefits 1 --lang ko --grass-out /tmp/fp-korean2.grass --backfill-ko-out /tmp/fp-backfill-ko.cypher --output /tmp/fp-sample-hana-ko.cypher`

신규 그래프는 생성된 Cypher를 사용자가 직접 로컬 Neo4j Browser에 붙여 넣어 실행한다. 기존 그래프는 backfill 파일을 실행한다. 스타일 파일은 Browser 창에 드래그하거나 `:style` 화면 Import를 시도한다.

## 한계 및 다음 할 일

- Browser 버전별 `caption: "{caption_ko}"` 적용은 미확인이다.
- 사용자가 수동으로 설정한 `label_ko`는 같은 매핑으로 덮어쓴다.
- 실데이터 재적재와 Neo4j 접속은 하지 않았다.
- Browser에서 스타일 캡션 확인 후 필요하면 사용법을 보완한다.
