# 11단계 OCR 대조 시트

PC: laptop

## 목적

스캔 PDF 페이지와 OCR 텍스트의 숫자 정보를 한 화면에서 대조하고, 판정 CSV를 내려받는 오프라인 HTML 도구를 추가했다.

## 사용법

```bash
UV_CACHE_DIR=/tmp/uv-cache PYTHONPATH=src:src/card_benefit uv run --locked --no-sync python -m payment_card.file_pipeline.extraction.ocr_review_sheet --ocr-dir /tmp/ocr-woori2 --documents src/card_benefit/data/index/woori/documents.csv --data-root src/data --output /tmp/ocr-review-priority.html --priority 20
```

생성된 HTML을 브라우저에서 열고 숫자마다 정상/오류/미확인을 선택한다. 오류인 숫자는 수정값을 입력하고 판정 CSV 다운로드 버튼을 누른다.

## 제한 및 다음 단계

HTML은 이미지와 OCR 본문을 포함해 파일 크기가 커질 수 있다. 낮은 DPI나 `--max-size-mb`로 크기를 조절한다. 브라우저 저장소가 차단되면 판정은 보존되지 않는다. 사용 후 CSV 판정을 검토해 정정 데이터 반영 범위를 결정한다.

검증 결과: 합성 OCR 대조 시트 테스트는 2개 통과했다. 지정 경로 테스트는 233개 통과, 모듈 점검 목록에 `ocr_review_sheet`가 없다는 커버리지 검사 1개가 실패했다. 목록 파일은 수정하지 않았다. 전체 수집을 요청한 명령은 `src/graphrag_chatbot/tests/test_flow.py`에서 `anthropic` 패키지가 없어 수집 오류로 중단됐다.

실제 실행은 우선순위 20페이지 HTML 3,603,953바이트, 전체 126페이지 HTML 11,004,630바이트를 만들었다. 숫자 토큰 신뢰도 연결은 4,729/4,729 (100.0%), sidecar 단어 본문 정렬은 121,292/121,301 (100.0%, 반올림), TSV 토큰/문맥 일치는 973/1,079 (90.2%)였다. 전체 출력 신뢰도 티어는 초록 2,580, 노랑 926, 빨강 1,223이다. 우선순위 출력은 초록 768, 노랑 409, 빨강 547이다.

확인 필요: 모듈 점검 목록 등록과 전체 테스트 수집은 이 작업 범위에서 처리하지 않았다. 실사용자 판정 CSV의 브라우저 저장/다운로드 동작은 자동화 브라우저로 확인하지 않았다. OCR 본문은 이력에 기록하지 않았다.
