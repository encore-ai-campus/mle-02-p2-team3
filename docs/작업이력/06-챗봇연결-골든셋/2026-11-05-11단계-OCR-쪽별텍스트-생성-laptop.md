# 11단계 OCR 쪽별 텍스트 생성

- PC: laptop
- 목적: canonical=Y, ocr_needed=Y인 우리카드 스캔 PDF의 페이지 텍스트를 기존 traceability JSON 구조로 만들고 OCR 결과를 검수할 수 있게 한다.
- 형식: `traceability-v1` 페이지 필드와 문서 SHA-256 유지. `doc_id.json`에 청킹 입력, `doc_id.ocr.json`에 Tesseract 설정, 페이지별 통계, 단어 confidence를 저장한다. 숫자 검수 CSV는 숫자 토큰 및 앞뒤 최대 10자 문맥과 confidence만 담는다.
- 통계: OCR별 단어·문자·한글·숫자 수, 평균 confidence, confidence 70 미만 단어 비율. 3단어 미만 페이지는 페이지를 유지하고 텍스트는 비운다.
- 한계: OCR 텍스트와 숫자는 사람이 원본 이미지와 대조해야 한다. 숫자 패턴은 지정된 단위/기간 표현만 찾으며 모든 서식을 포괄하지 않는다.
- 사용 명령: `PYTHONPATH=src:src/card_benefit uv run --locked --no-sync python -m payment_card.file_pipeline.extraction.ocr_pages --documents src/card_benefit/data/index/woori/documents.csv --doc-id <doc_id> --data-root src/data --output-dir /tmp/ocr-sample --report-csv /tmp/ocr-sample/numeric_tokens.csv` (계획만 출력)
- 실행 명령: 위 명령에 `--execute` 추가
- 다음 할 일: 숫자 토큰과 페이지 텍스트를 이미지와 대조하고 수정 사항을 반영한 뒤, 필요할 때 전체 OCR을 실행한다. 점검 목록 행과 인덱스 행은 사용자 반영 대기.
