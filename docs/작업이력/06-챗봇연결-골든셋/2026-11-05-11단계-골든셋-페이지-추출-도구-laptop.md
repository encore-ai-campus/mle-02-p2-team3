# 11단계 골든셋 페이지 추출 도구

- PC: laptop
- 목적: 추출 결과에 이미 나타난 사실에 질문이 편중되는 문제를 줄이기 위해, 추출 산출물을 사용하지 않고 정본 PDF 페이지를 무작위 층화 표집한다.
- 규칙: canonical=Y, 기본 OCR 제외, 글자 수 최소 기준, issuer×doc_role 층화, 문서당 최대 페이지 수, 약 15% 정답없음 슬롯. 페이지 링크는 비고에 기록한다.
- 사용: Google Sheets에서 CSV를 연다. 비고 링크를 눌러 PDF 페이지를 확인하고 질문과 답을 직접 작성한다. 완성 CSV는 `UV_CACHE_DIR=/tmp/uv-cache PYTHONPATH=src:src/card_benefit uv run --locked --no-sync python -m payment_card.file_pipeline.chat.golden_set <완성.csv> --output /tmp/questions.json`으로 변환한다.
- 제한: 글자 수 기준은 표나 이미지 위주 페이지를 잘못 판단할 수 있다. 초안 CSV는 질문·유형·핵심 사실 등이 비어 있어 작성 후 변환해야 한다. 유형, 그래프 범위, 작성자는 변환기 필수값이며 그래프 범위는 `우리/팀원/둘다` 중 확인해 입력한다.
- 상태: 아직 커밋하지 않음.
