# 11단계 골든셋 평가 도구

## 목적
CSV 골든셋과 저장된 답변 JSONL 및 그래프 CSV를 사용해 DB·LLM 연결 없이 검색 근거, 원자 사실, 숫자 근거, 반복 안정성을 평가한다.

## 지표 정의
- 강한 근거 일치: 같은 문서 해시·쪽에서 위치 구간이 겹치는 골든 span 비율. 기본 겹침은 한 글자 이상이며 `--overlap 50`은 골든 span 길이의 50% 이상이다.
- 약한 일치: 위치가 없거나 모호한 경우 문서·쪽만 일치한 수. 직접 노드 근거와 끝점 엣지 근거를 기본 포함하며 `--strict-node-evidence`는 직접 근거만 사용한다.
- `hit`는 골든 span 중 하나 이상 회수, `span_recall`은 회수 span/전체 span이다. 정답 없음은 검색 점수에서 제외한다. 40개 이상 반환은 상한 절단 가능성 표식이다.
- 사실 일치는 answer_eval의 숫자·단위, 이름, 해시 판정 함수 결과를 사실별로 기록한다. groundedness는 답변 숫자 문자열이 검색 컨텍스트에 있는지만 확인하며 의미적 충실성은 측정하지 않는다.
- tier_linked는 마침표·줄바꿈으로 나눈 한 문장에 구간 수치와 한도 수치가 함께 있는지 보는 규칙 기반 보조 표시다.
- 반복 CI는 문항(옵션에 따라 변형 그룹)을 재표집한 부트스트랩 95% 구간이다. 변형 질문을 독립 표본으로 세면 과신할 수 있다.

## 사용법
골든 CSV는 `golden_set.py`의 기본 열과 위치·슬라이스 확장 열을 사용한다. 먼저 기존 골든셋 변환기로 `/tmp/golden/golden-v1.json`을 만든다. 질문용 결과 세 번은 각각 다른 출력 경로로 저장한다.

```sh
UV_CACHE_DIR=/tmp/uv-cache PYTHONPATH=src:src/card_benefit uv run --locked --no-sync python -m card_benefit.payment_card.file_pipeline.chat.golden_set /tmp/golden/golden-v1.csv --output /tmp/golden/golden-v1.json
UV_CACHE_DIR=/tmp/uv-cache PYTHONPATH=src:src/card_benefit uv run --locked --no-sync python src/card_benefit/payment_card/file_pipeline/chat/run_eval.py /tmp/golden/golden-v1.json --mode answer --execute --output /tmp/golden/r1.jsonl
```
반복 실행은 출력 파일을 r2/r3로 바꾸어 실행한다. 집계 CLI 예:

```sh
UV_CACHE_DIR=/tmp/uv-cache PYTHONPATH=src:src/card_benefit uv run --locked --no-sync python -m card_benefit.payment_card.file_pipeline.chat.golden_eval --golden /tmp/golden/golden-v1.csv --results /tmp/golden/r1.jsonl /tmp/golden/r2.jsonl /tmp/golden/r3.jsonl --csv-dir /tmp/fp-check-hana-st2 --csv-dir /tmp/fp-check-woori-st2 --output-dir /tmp/golden-eval/v1
```

## 한계와 다음 할 일
같은 쪽 위치가 겹쳐도 다른 문장일 수 있다. groundedness는 컨텍스트 내 숫자 존재만 검사하므로 의미 충실성 판정이 아니다. tier_linked는 문장 내 공존만 검사한다. 반복 변형 질문은 그룹 단위 집계를 권장한다. 두 설정의 쌍체 비교는 라이브러리 함수는 있으나 CLI 출력은 미완성이다. 다음으로 실제 골든셋과 해당 질문용 결과 파일을 받아 검수자 판정과 비교한다.

## 커밋 전
합성 입력 테스트, 표준 테스트 마지막 결과, 점검 목록 등록 필요 사항을 확인한다. 커밋은 사용자가 수행한다.
