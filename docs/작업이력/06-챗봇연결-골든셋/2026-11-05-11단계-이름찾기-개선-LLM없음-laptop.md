# 11단계 이름 찾기 개선 (LLM 없음)

- PC: laptop
- 목적: 질문 문자열에서 규칙 기반으로 그래프 시드 이름을 골라 검색 회수율을 확인한다.
- 규칙: 소문자·기호 제거·공백 결합·한국어 조사 제거, 문자 2-gram Jaccard/포함 점수, 0.15 임계값, 짧은 이름 제외·정규화 중복 빈도 패널티, Card/Benefit 우선, Document 제외, 이름순 동점 정렬. 인덱스는 평가당 한 번 만든다.
- 임계값: 사람형 앞 7개에서 0.05~0.50 비교. 0.15는 노드 회수율 1.000, 시드 재현율 0.857, 정밀도 0.353으로 0.20보다 개발 구간 시드 재현율이 높아 선택.
