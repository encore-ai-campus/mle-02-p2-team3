## 못 한 것과 남은 위험

- **새 run 3건(우리 OCR, 하나 복구, 우리 복구)은 아직 DB 에 적재하지 않았다**(사용자 실행 단계). 적재 후에는 챗봇 뷰에 run 필터가 없어 자동으로 노출된다. 새 run 은 기존 Card 를 공유하므로 카드 중복은 생기지 않지만, 나중에 기존 run 을 지울 때 새 run 엣지가 외래키(ON DELETE 없음)로 삭제를 막는다(데이터 손상이 아닌 거부; 새 run 을 먼저 삭제해야 함). 이 삭제 동작은 스키마 정의를 읽어 확인했고 실제 실행은 하지 않았다.
