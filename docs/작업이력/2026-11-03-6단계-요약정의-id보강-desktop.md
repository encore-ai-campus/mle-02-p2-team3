## 변경

- `batch.py`: 모호 위치는 hard 실패에서 분리해 경고로 집계하고, `review_required`에는 위치 실패나 모호가 있는 청크를 센다. `quote_location_failure`는 실패로 남기며 `quote_location_ambiguous`는 추출 성공과 공존할 수 있다. `failures_by_code`는 모든 실패 코드, `warnings_by_code`는 모호 코드만 집계한다.
- `cli.py`, `batch.py`: `summarize` 명령을 추가했다. 기존 청크 결과만 읽고 문서별 요약을 다시 만든다(LLM 호출 없음). 입력 청크와 결과의 문서 해시·페이지·청크 ID가 맞는지 확인하며, 빠진 결과 수는 `missing_results`에 쓴다. 목록에 요청했지만 청크 폴더에 없는 ID는 요약을 쓰기 전에 오류로 반환한다. 프롬프트 버전별로 결과 폴더를 나눠 각각 집계한다.
- `runner.py`: 반복되는 인용문은 원문 인용문을 보존하고 `location=null`로 둔다. 동일 문구가 여러 곳에 있을 때 첫 위치를 임의로 근거로 삼지 않으며, 모호 오류에 발생 횟수를 남긴다.
- `prompt.py`: ID 예시를 `b1`, `c1`, `l1`, `t1` 형태로 통일하고, 관계가 해당 ID를 그대로 참조하게 지시했다. Python에서 ID를 자동 정규화하지 않는다.
- 사용법을 file_pipeline README에 추가했다.
