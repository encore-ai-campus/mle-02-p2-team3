# 작업 이력: 온톨로지 규칙 검토 (laptop)

- 작업일: 2026-11-03
- 범위: 문서만 수정. 코드와 테스트는 변경·실행하지 않음.
- 기준 분석: 전체 청크에서 한도·택1·제외 표현을 검토한 결과. 단어 패턴 집계는 거친 탐색치로, 규칙을 입증하는 통계로 쓰지 않음.

## 반영
- 혜택 문장에 붙은 한도는 해당 혜택에 연결하고, 공유 통합 한도는 같은 `Limit`을 여러 혜택이 참조하며 `shared=true`로 표시한다.
- 값과 라벨이 분리된 표의 한도 연결은 7개 청크만 확인되어 규칙 확정을 보류하고, 6단계 추출 시범 결과를 보고 정하기로 했다.
- 품목 택1은 한 혜택에 여러 `Target`을 연결하고 선택 표현을 원문에 보존한다. 할인·적립 택1은 새 관계 없이 `Benefit.method=None`과 `Condition`으로 표현한다.
- 전월 실적 제외 목록은 항목별로 나누지 않고 `Condition(kind=EXCLUDE)` 하나에 전체 문구를 보존한다. 혜택에서 제외되는 가맹점·업종이 분명할 때만 `EXCLUDES`를 쓴다.
- 기존 문서에서 제외 목록 전체를 `EXCLUDES`로 다룰 수 있게 읽히던 표현을 위 경계에 맞게 고쳤다.

## 남은 확인
- 할인·적립 택1은 데스크탑 표본의 실제 문장과 대조가 필요하다.
- 표의 한도 라벨 연결은 6단계 추출 시범에서 오류 양상을 확인한 뒤 결정한다.
- 변경 사항을 코드 검증으로 확인하지 않았다(문서 전용 변경).
