# 추출 대조표 자동 점검 시범

- 작업일: 2026-11-03
- PC: laptop
- 범위: 기존 사람이 검토한 5개 청크의 기계적 점검과 사람 판정 비교

## 입력과 처리

- 검토표: `/tmp/review_sheet_pilot.md` (사람 표시가 있는 기존 표)
- 원문 추적: `/home/lee/pilot_work/trace/hana`
- 청크: `/home/lee/pilot_work/chunks/hana`
- PDF: 저장소 `src/data`의 문서 5개
- 원본 표와 추출 JSON은 변경하지 않았다. 자동 보고서 `/tmp/review_auto_audit_20261103.json`에는 청크 ID, 분류, 점검 코드와 집계만 있고 원문 인용·추출값은 없다.

## 직접 확인한 결과

- 자동 점검 대상은 **5개 청크, 124개 추출 근거 행**이다. 원문과 추출값 비교표의 `항목 없음` 자리표시 행 1개는 제외했다.
- 기존 사람 표시: 일치 111, 누락 4, 값 오류 1, 미검토 8.
- 자동 점검은 인용문이 저장 쪽 원문에 있는지, 제공된 쪽 위치의 글자가 인용문과 맞는지, 표에 보인 인용문 조각과 일치하는지, 숫자 값이 인용문에 있는지 확인했다. 혜택 방법 필드가 비어 있는 행은 후보로 표시했다.
- 저장된 `out3` 결과를 함께 넣어 관계 끝점 ID가 결과 엔티티를 가리키는지, 관계 유형의 허용 엔티티 쌍과 맞는지도 검사했다. 이번 5개 청크에서는 관계 구조 오류 후보가 없었다. 관계가 원문 의미로 뒷받침되는지는 별도 판정이다.
- 기존 사람 판정과 대조한 결과: 참양성 4, 거짓양성 0, 거짓음성 1, 참음성 111. 즉 사람 판정이 있는 116행 중 자동 점검은 사람의 누락 4건을 후보로 잡았지만, 값 오류 1건은 놓쳤다. 표본이 작으므로 일반 정확도 지표로 해석하지 않는다.
- 미검토 8행 중 4행은 자동 점검 후보가 있고, 4행은 기계적 신호가 없었다. 신호가 없다는 이유로 정확하다고 확정할 수 없어 8행 모두 사람 확인 대상으로 남긴다.
- 쪽 PDF 텍스트 추출에서 인용문을 확인하지 못한 78행은 4개 쪽에 모였다. 이를 행별 추출 오류로 세지 않고 **4개 쪽의 시각 확인 후보**로 묶었다. 기본 Python에는 PyMuPDF가 없어 pypdf 텍스트 추출을 보조 신호로 썼으며, PDF 레이아웃은 직접 렌더링해 확인하지 않았다.
- 혜택 단어가 있으나 위치가 연결된 인용 근거로 덮이지 않는 문장 후보는 64개였다. 이 규칙은 넓게 잡는 휴리스틱이며 실제 누락 64건이라는 뜻이 아니다. 이 수치는 자동 누락 판정에 쓰지 않는다.

## 판단과 한계

- 현재 도구는 위치·인용·숫자·빈 필드의 **우선 확인 후보를 모으는 보조 점검**으로 사용할 수 있다.
- 값 오류 1건을 놓쳤으므로 결과를 자동 승인하거나 사람 검토를 생략하는 데 쓸 수 없다. 관계 의미, 조건·대상 연결, 표의 열 대응, 문맥상 수치 귀속은 자동 판정하지 않는다.
- 혜택 방법의 빈 값은 온톨로지에서 허용될 수 있으므로 오류 확정이 아닌 사람 확인 후보로만 표시한다.
- 64개 단어 후보는 잡음이 크다. 다음 확대 전에 후보 규칙을 좁히고, 독립된 표본에서 오탐·미탐을 다시 비교한다.

## 실행 및 검증

```bash
PYTHONPATH=src:src/card_benefit python -m payment_card.file_pipeline.extraction.review_auto_audit \
  --sheet /tmp/review_sheet_pilot.md \
  --chunk-dir /home/lee/pilot_work/chunks/hana \
  --trace-dir /home/lee/pilot_work/trace/hana \
  --result-dir /home/lee/pilot_work/out3 \
  --output /tmp/review_auto_audit_20261103.json
```

- 새 자동 점검 테스트 6개와 기존 검토표 생성·집계 테스트 6개: 총 **12개 통과**.
- `git diff --check` 통과.
- 네트워크, LLM API, DB·Storage는 사용하지 않았다. 전체 테스트 스위트는 실행하지 않았다.
