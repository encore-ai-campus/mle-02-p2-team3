# 11단계 챗봇 연결 뷰 설계 (laptop)

- `fp_chat.nodes`와 `fp_chat.edges`를 위한 읽기 전용 SQL 뷰 및 DB 없는 정적 테스트를 추가했다.
- 원본 그래프 ID를 md5 기반 UUID로 투영하고, `fp_evidence`에서 문서 노드와 최대 3개 `SUPPORTED_BY` 연결을 만든다. 문서 요약은 해시 앞 8자와 위치 정보만 포함한다.
- 뷰는 원본 `fp_*`를 참조하며 `service_role`에 SELECT만 부여한다. PostgreSQL 15+ 기본 뷰 권한 동작과 원본 RLS 정책 부재의 영향을 SQL 주석에 기록했다.
- 실제 DB 접속, 뷰 실행, RLS 역할별 결과는 확인하지 않았다. 챗봇 수정은 적용하지 않고 별도 패치 텍스트로 제안한다.
