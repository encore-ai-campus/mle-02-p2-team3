# 개인 hg-commit·hg-bottleneck 스킬 기록

- PC: laptop
- 날짜: 2026-11-04
- 상태: 문서 확인 및 기록 완료, 커밋 전

## 저장소 밖 개인 도구

아래 스킬 파일을 읽어 위치와 사용법을 확인했다. 두 도구는 개인 경로에 있어 팀 저장소에 포함되지 않으며, 데스크탑에서도 사용하려면 각 PC에 따로 복사해야 한다.

- `~/.claude/skills/hg-commit/`: `SKILL.md`, `exclude.txt`. 사용자가 `/hg-commit`을 직접 입력할 때 동작하며 테스트, 제외 목록 적용, 안전 점검, 파일별 명시적 스테이징 후 커밋을 진행한다. `/hg-commit push`는 여기에 푸시 단계를 더한다. 제외 경로는 `exclude.txt`만 수정하면 다음 호출부터 적용된다.
- `~/.claude/skills/hg-bottleneck/`: `SKILL.md`, `check.sh`. check.sh는 읽기 전용으로 커밋 상태, 테스트, 돌고 있는 일, 문서 정합성, 키·접속 문자열 노출의 5항목을 점검한다. 스킬 지침은 실행 시 스크립트 출력 원문을 먼저 제시하도록 한다.

`src/AGENTS.md`의 `## Codex 작업 공통 규칙`은 저장소별 문서·코드 작업 경계를 일관되게 지키기 위한 규칙이다. 이 절은 파일 범위와 git 금지, 민감·원문 데이터 취급, 실행 경로, 표준 테스트와 사실 기반 보고·완료 확인을 정한다. 절은 `src/AGENTS.md`의 점검용 노트북 지침 바로 뒤에 있고 불릿 9개로 구성돼 있다. 이 파일이 데스크탑에 반영되는 시점은 해당 PC에서 pull한 뒤다. Codex가 매 작업마다 이 파일을 반드시 읽는다는 보장은 없다는 점은 추정이다.
