# 우리카드 브랜드서비스 중복 목록과 Drive 폴더 정리

- PC: laptop
- 날짜: 2026-11-04
- 상태: 커밋 전

## 직접 확인한 사실

- 우리카드 `documents.csv` 기준 브랜드 서비스는 29행이며 canonical Y 21개, N 8개다. sha 동일 파일은 5그룹 13개로, 대표 5개와 중복 8개다.

| 브랜드 서비스 | SHA-256 접두사 묶음 |
|---|---|
| MC_W 기본 | `2af8892d`, `ab94e99a` |
| UPI_P 기본 | `c11b6d49`, `d9fcfa6d` |
| MC_P.T 기본 | `64f5730d`, `b75196c8`, `f6d01089` |
| VISA-I 기본 | `696d7877`, `ad814698`, `f039d8cf` |
| VISA-P 기본 | `550cec24`, `85eaceda`, `9be332d4` |

- 하나카드 브랜드 서비스 canonical은 16개이며 우리카드와 sha 일치 파일은 0개다. 하나카드 브랜드 서비스 15개는 팀원이 이미 등록했고, 미등록 1개는 UnionPay 2019 파일이다. 원격 main의 `src/card_benefit/data/markdown/common` 매니페스트 등록 수는 15개로 확인된 작업 자료에 기록되어 있다. 우리카드 브랜드 서비스 등록은 0개다.
- 우리카드 브랜드 서비스 canonical 21개 중 19개는 OCR이 필요한 이미지 PDF다. 작업 당시 로컬 OCR은 미설치이고 모델 파일도 없었다. OCR 대상 대표 문서는 우리카드 45개(126쪽), 하나카드 2개(4쪽)이며 팀원 파이프라인에는 OCR 기능이 있다.
- 중복 PDF 13개를 저장소 밖 `~/pilot_work/handoff/woori_brand_dup13/`에 모았다. 파일명은 SHA-256 8자리 접미사를 보존하고 그룹 크기 3+3+3+2+2를 확인했다.
- 사용자 요청에 따라 Drive 폴더 `우리카드 공통 브랜드서비스 중복 PDF 확인` 안의 상품안내장 PDF 25개를 휴지통으로 이동했다. 23개를 먼저 옮긴 뒤 분류기에서 거부한 2개도 재지시로 이동했다. 영구 삭제가 아니며 폴더는 비어 있다.
- Drive 중복 후보 탭은 8행이며 13개 PDF의 해시와 일치했다. Drive의 `woori_all/credit` 폴더에는 상품안내장이 100개 이상 있고, 브랜드 서비스 PDF는 Drive 어디에도 없는 것으로 확인했다. Drive 계정·폴더 ID·링크는 기록하지 않는다.

## 확인 한계와 추정

- 이 기록은 작업 과정에서 확인된 로컬 인덱스·해시와 사용자 제공 Drive 작업 결과를 요약한다. Drive 상태는 이 문서 작성 시점에 다시 조회하지 않았다.
- 19개 이미지 PDF의 OCR 텍스트를 현재 확보할 수 없고 모델 파일도 없어 추출 결과는 미확인이다. OCR이 확보되면 추출 가능하리라는 기대는 **추정**이다.

## 못 한 것

- 로컬 중복 PDF는 사용자가 업로드하기로 해 Drive 폴더에 올리지 않았다.
- OCR을 실행하거나 19개 이미지 PDF의 텍스트 추출 여부를 검증하지 못했다.
