# 프로젝트 지도 단계 우선순위 정합화

- PC: laptop
- 날짜: 2026-11-09
- 브랜치: `feat/file-pipeline-extraction-integrate`, 시작 시 HEAD `5ce52f1`
- 사용자 요청에 따라 서브에이전트 3명이 프로젝트 지도, 5~7단계 근거, CLUB1 화면 코드 경로를 각각 읽기 전용 검토했다.

## 확인한 사실

- 시연 차단은 파이프라인 11단계의 CLUB1 화면 질문이다. 사용자는 화면에서 실패했다고 보고했지만, 실패 화면·실제 검색 결과·답변 근거가 없어 원인은 확정되지 않았다.
- v2 화면은 `app_v2.py`에서 분석·탐색·답변 생성을 직접 호출한다. `fp_chat_patch.py`의 `answer()` 경로와 동일하지 않다.
- UI 테스트는 CLUB1 질문 문구 표시와 첫 번째 예시 질문 전달을 확인하지만, CLUB1 실제 검색·답변 정확성은 확인하지 않는다.
- 5단계는 `ONTOLOGY_V1`을 내부 구현 기준으로 사용한다. `Condition`·`Limit` 의미 경계와 비교 형식·팀 공통 계약은 미확정이며, 의미 변경 필요성이 확인되기 전 v2로 바꿀 근거는 없다.
- 6단계는 실행·스키마 성공과 의미 정확도를 구분해야 한다. 2026-11-08 표본은 의미 검토 5개 부분 통과·1개 실패, 모호한 인용 33건 기록이 있다. 전체 품질·비용과 재처리 뒤 전체 상태는 미확인이다.
- 7단계 표본 판정 도구는 혜택이 있는 청크를 모집단으로 사용한다. 그 표본만으로 빈 결과 청크의 누락률을 판단할 수 없다. 사람 판정과 사전 합의한 통과 기준은 미완료다.

## 변경

- `docs/프로젝트-지도.md`에서 시연 P0(11단계)와 기술 기반 P1(5→6→7단계)을 분리해 표기했다.
- 5~7단계 표에 다음 행동을 추가하고, API 호출 성공과 의미상 추출 성공을 구분했다. 검증 모집단에는 빈 결과가 포함되어야 한다는 한계를 기록했다.
- CLUB1 상태를 “사용자 화면 테스트 대기”에서 “실패 보고 후 원인 확인 대기”로 정합화하고, 화면의 실제 호출 경로와 테스트가 보장하지 않는 범위를 연결했다.
- 골든셋 항목의 행동은 보류 해제 뒤에만 시작하도록 문구를 분명히 했다. 골든셋은 계속 보류다.

## 10분 추가 점검

- 서브에이전트 3명이 각각 현재 UI diff, 5~7단계 내부 계약·산출물 가용성, 10분 범위의 확정 사실을 읽기 전용 확인했다. 별도 비판 검토는 표본 30/36안, 전체 정확도 주장, 실행 비용·8단계 선행 조건을 점검했다.
- 현재 v2 화면은 여러 구간 예외를 한 곳에서 받아 예외 종류만 표시하며, 실패 단계와 그 시점의 후보·그래프를 보존하지 않는다. 분석 후보·캐시 적중·시드 ID, 거절 보정 전 답변, 근거 조회 상태도 재현 자료로 함께 남지 않는다. 이는 진단 관찰 공백이며 CLUB1 원인으로 확정하지 않았다.
- 미커밋 UI 변경에서 질문 기반 후보 조회와 거절 보정이 추가됐다. 따라서 `5ce52f1`만으로는 현재 CLUB1 질문 카드가 재현되지 않을 수 있다. 재현 시 현재 작업 트리 기준을 기록해야 한다.
- `prompt.py`의 `Condition.amount` 지시는 실제 `Condition` 필드(`text`, `kind`, `min_amount`) 및 `extra="forbid"`와 불일치한다. 스키마 거부 위험은 확인했지만 실제 실행 결과의 원인인지는 미확인이다. 프롬프트 수정과 회귀 검증은 이번 점검에서 하지 않았다.
- `result_a.py`의 출력 필드 구성은 이름·유형·숫자 필드를 포함하지만 Condition·Limit·Target의 `text`를 포함하지 않는다. Result A 비교에서 원문 표현의 의미가 필요한지 먼저 결정해야 한다.
- 확인한 저장소 내부 데이터·파이프라인·사용자 폴더 경로에는 대응 추출 결과 `*.result.json`·`*.jsonl`이 보이지 않았다. 외부 실행 경로는 열지 않아 전체 결과의 재집계 가능성은 미확인이다. 기존 정확성 판정표는 혜택 있는 청크만 모집단으로 사용한다.
- `docs/프로젝트-지도.md`에 이 근거와 미확인 범위를 추가했다. 테스트·Streamlit·DB·외부 API는 실행하지 않았고 `.env`와 외부 실행 경로는 열지 않았다.
