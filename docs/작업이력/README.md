# 작업이력 인덱스

## 쓰는 법

- 이력 파일은 아래 단계 폴더 중 하나에 둔다. 새 파일은 맞는 폴더에 만들고, 어디에도 맞지 않으면 `99-기타`에 둔다. 파일을 한 폴더에서 다른 폴더로 옮기지 않는다(링크와 다른 PC의 풀이 깨진다).
- 이력 파일 이름은 `YYYY-MM-DD-<주제>-<pc>.md`이고 `<pc>`는 `desktop` 또는 `laptop`이다. 다른 PC가 만든 파일은 고치지 않고, 덧붙일 내용은 새 파일로 쓰고 링크한다. (같은 파일을 두 PC가 고치면 풀할 때 충돌한다.)
- 이력에는 한 일, 실행한 검증과 결과, 못 한 것과 남은 위험, 다음에 할 일, 관련 커밋 해시를 적는다. 직접 확인한 사실과 추측을 구분한다.
- 작업을 시작하기 전에 `git fetch` 후 이 표와 최근 이력을 읽는다. 풀(병합)은 확인 후에 한다.
- 끝낼 때 아래 표에 한 줄을 더한다. 여러 PC가 이 표를 고치므로 **맨 아래에 한 줄씩만** 추가한다.
- 접속 정보와 PDF 전체 원문은 넣지 않는다.
