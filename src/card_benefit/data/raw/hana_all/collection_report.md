## 3. 문서 종류와 파일명 규칙

파일명은 `카드구분_상품명_문서종류_원본파일명.pdf` 형식이다. manifest의 `문서구분` 열에서 다음 세 종류를 구분한다.

| 문서구분 | 파일명 표시 | 의미 |
|---|---|---|
| 공식 원본 PDF | `상품설명서(공식PDF)` | PC 상세 페이지의 「상품약관보기」 링크(`/leaflet/..`), 또는 모바일 상세 HTML에 들어 있는 「상품안내장 보러가기」 링크에서 받은 원본. |
| 공식 원본 PDF(URL 추정 확인) | `상품설명서(공식PDF,URL추정확인)` | 상품 페이지에 PDF 링크가 없는 카드. 목록 API의 디자인코드(`DSGN_CD`)와 사이트에 실제로 게시된 leaflet 날짜 32개를 조합해 공식 서버 URL을 순차 GET으로 확인한 원본. 최신 날짜부터 시도해 처음 확인된 파일을 받았다. |
| 웹페이지 변환 PDF | `웹페이지변환PDF_상품상세(모바일)` | Chrome(Playwright, 시스템 Chrome 채널)의 인쇄→PDF 기능으로 모바일 상품 상세 페이지를 저장한 파일. |
| 공통 | `common/공통_...` | 공통약관 3종, 국제브랜드(VISA/Mastercard/AMEX/JCB/UnionPay) 서비스 안내 PDF. 여러 카드가 공유한다. |

**URL 추정 확인 문서의 한계**
- 상품 페이지가 직접 제공하는 문서가 아니다.
- 사이트에 게시된 적 없는 날짜로 올라온 더 최신 판이 있을 수 있다. 따라서 최신판이라고 보장할 수 없다.
- 이 문서가 있는 카드도 웹페이지 변환 PDF를 함께 만들었다.

**웹페이지 변환 PDF 생성과 검증**
- 모바일 상세 페이지는 탭 없이 한 페이지로 구성되어 있다. 탭 UI(`role=tab`)가 발견된 상품은 없었다.

## 6. 확인 사항과 누락 가능성

- **확인된 범위**
  - 2026-10-30 기준 PC와 모바일 공식 카드 목록(신용, 체크, 제휴)에 게재된 개인 카드 전체 148개 항목(서로 다른 상품명 143개).
  - 하위 탭 합계, 목록 API의 totalCnt, 수집 결과 행을 대조했다. 목록에는 있는데 manifest에 없는 상품은 0개다.
- **미확인 범위와 한계**
  1. **발급 중단 상품**: 공식 홈페이지에 발급 중단 카드 목록이나 메뉴가 없다.
     - 상품공시실은 수수료율과 체크카드 발급 실적만 공개한다.
     - 「신용카드설명서조회」는 본인인증이 필요해서 사용하지 않았다.
     - 따라서 발급 중단 상품은 수집하지 않았다. manifest의 발급상태는 모두 "발급 가능(공식 상품 목록 게재)"이다.
     - 목록에 있어도 신청 버튼이 없거나, 대상자 제한(장학생, 군인, 지자체 등)이 있는 상품이 있다. 실제 신청 가능 여부는 확인하지 않았다.
  2. **가족카드, 멀티카드, 선불·기프트카드**: 별도 메뉴라서 조사 범위에서 뺐다.
  3. **기업·법인카드**: 기업 사이트 메뉴(`schID=ccd`)에 따로 있다. 지시대로 수집하지 않았고 상품 수도 세지 않았다.
     - 「약관/서식」에 신용·체크카드 기업회원 약관이 따로 게시되어 있다는 점만 확인했다.
  4. **최신판 여부**: 파일명 날짜와 준법심의 일자만으로는 시행일이나 법적 효력을 확정할 수 없다. 특히 URL 추정 확인 문서는 더 최신 판이 있을 수 있다.
  5. **본문에서 상품명이 확인되지 않은 공식 PDF 10건**: 하나 더 소호, 그린, CLUB H AMEX 리저브, 원더 2.0 공통 안내장 등.
     - 상품명이 이미지로 표기된 경우로 보인다.
     - 상품 페이지 링크나 디자인코드로 연결된 문서지만, 텍스트로 상품명을 다시 확인하지는 못했다.
  6. **원더카드 2.0 조합형**: 공통 안내장만 있다. 조합별 혜택은 웹 변환 PDF에 있다.
  7. **텍스트 추출**: PDF 텍스트가 추출된다고 해서 표의 행·열 관계가 정확히 보존된다는 뜻은 아니다. 정제 단계에서 별도로 검증해야 한다.
