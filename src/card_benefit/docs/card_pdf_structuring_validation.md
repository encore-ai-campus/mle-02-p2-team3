# 카드 상품 PDF 확보 및 구조화 가능성 검증

검증일: 2026-10-29. 이 문서는 기존 조사 보고서와 별도의 검증 기록이다. **PDF를 읽을 수 있다는 것과 혜택·조건·표를 정확한 구조 데이터로 자동 변환할 수 있다는 것은 다르다.** 본 검증은 실제 파일 다운로드, 두 추출기의 페이지별 텍스트와 기본 표 탐지, 대표 항목의 원문 이미지 대조까지 수행했다. 완전한 구조화 파이프라인이나 전체 필드의 정확도는 검증하지 않았다.

## 실행 환경 및 방법

- Windows PowerShell 터미널 사용 가능. 시스템 Python 3.14에는 PyMuPDF·pdfplumber가 없었다. 프로젝트 `.venv`에는 PyMuPDF가 있고 pdfplumber는 없었다. `pyproject.toml`과 `uv.lock`에는 PyMuPDF 의존성이 이미 있다.
- 프로젝트 의존성 파일을 수정하지 않고 `uv run --no-project --with pdfplumber --with pymupdf`의 별도 임시 환경을 사용했다. 실제 버전은 PyMuPDF **1.28.2**, pdfplumber **0.11.10**이다.
- PowerShell `Invoke-WebRequest`로 아래 공식 URL 7개를 OS 임시 폴더에 실제 다운로드했다. 최초 샌드박스 내 Python `urllib` 요청은 `WinError 10013` 네트워크 권한 제한으로 실패했으며, 승인된 네트워크 접근으로 재시도했다. 7개 최종 다운로드는 모두 성공했다. PDF는 저장소에 추가하지 않았다.
- 각 페이지에서 PyMuPDF `get_text()`와 pdfplumber `extract_text()`를 실행해 글자 수와 대표 검색어를 확인했다. pdfplumber 기본 `extract_tables()`의 탐지 결과를 살폈다. 혜택·실적·제외와 표가 있는 대표 페이지를 PyMuPDF로 렌더링해 원문 이미지와 추출 결과의 대표 값 및 문맥을 수작업 대조했다. 페이지 번호는 1부터다. 키워드 존재는 해당 문구의 전체 의미나 표 관계가 정확하다는 뜻이 아니다.
- 표 자동 결과는 기본 옵션의 실험이며 수동 보정, 별도 위치 기반 규칙, OCR, LLM 추출은 수행하지 않았다. 대표 값의 일치는 전체 문서의 모든 항목이 일치한다는 뜻이 아니다.

## 대표 실패 및 근거 해석

1. **읽기 성공, 표 추출 실패 — STYLE·PLAY:** 두 PDF의 모든 페이지에서 문자가 추출되고 해당 숫자도 보인다. 그러나 기본 표 탐지가 0개라 셀과 혜택의 대응까지 성공했다고 할 수 없다. ONE PICK과 STYLE/PLAY가 각각 같은 월 5천원을 가지는 경우처럼 동일 값만 검색하면 구분이 어렵다.
2. **부분 표 추출 — BT·에너지 더블:** BT는 `['할인율','월 할인한도']`와 `['1.5%\n1.2%\n1.0%\n0.5%', '300만원\n한도 없음']`으로 추출돼 금액 구간별 행이 보존되지 않는다. 에너지 더블은 대상 가맹점 열이 비어 있고 병합 셀이 비어 나온다. 텍스트의 수치가 있어도 혜택→조건→한도 관계를 그대로 적재해서는 안 된다.
3. **누락된 셀 — 건담 X:** 2쪽 통합할인한도 표는 pdfplumber에서 마지막 셀이 `None`이지만 원문에는 4만원이 보인다. 값의 텍스트 검색 성공과 표 셀 구조화 성공이 다르다.
4. **이미지 기반 혜택 표 — KB:** 페이지의 일부는 검색 가능한 텍스트지만 혜택과 한도 표는 텍스트 추출기에 잡히지 않는다. 문서 전체를 텍스트 PDF 또는 이미지 PDF로 단순 분류하면 이 혼합 형태를 놓칠 수 있다.
5. **추출 오류로 오인한 원문 문구 — 건담 X:** 이전 독립 비교 보고서는 `상품/선불전자지급수단`을 추출 과정에서 깨진 것으로 추정했다. 이번에 PDF를 확대 렌더링해 확인한 결과, **PDF 원문에도 '상품/'으로 표시**돼 있다. 문서상의 오기인지와 의도한 법적 의미는 확인하지 못했다. 이 문구를 '상품권'으로 자동 정규화하거나 실적 제외로 확정하지 않는다. 이전 보고서의 해당 의심 사유는 이 결과로 정정하되 별도 보고서 원문은 수정하지 않았다.

## 확보 문서의 식별 및 출처

파일 크기와 SHA-256은 검증 당시 다운로드한 바이트의 식별값이며, 최신 유효 버전이나 시행일을 보장하지 않는다. 링크는 위 표에 직접 연결했다.

## 판단과 남은 검증

7개 PDF, 총 11페이지에서 두 추출기의 비어 있지 않은 텍스트를 확인했다. 대표 혜택·실적·제외 문구는 하나·신한 6종에서 추출했고, KB는 실적·제외 문구만 확인했으며 혜택 표는 이미지에서 수동 확인했다. 자동 표의 표본 구조가 원문과 일치한 사례는 신한 S2 적립률 표이며, 나머지는 미탐지 또는 누락이 확인됐다. 이는 표본 수준의 결과이며 카드별 모든 표에 대한 성공률이 아니다.

다음 단계에서는 최신 공식 버전 및 재배포 조건 확인, 페이지 이미지와 추출 청크의 위치 연결, 표의 병합 셀 보정 및 KB 이미지 영역 OCR 가능성 검증, 원문–구조화 결과의 표본별 정답 검토가 필요하다. Neo4j 적재·Cypher·GraphRAG와 MCP 검증은 수행하지 않았으며 별도 단계다.
