## C. 파일 검증 결과

- 서로 다른 카드 상품: **10종** (체크 5 · 신용 5), 기존 검토 4종 포함
- PDF 다운로드 성공 10 / 텍스트 추출 가능 10 / 카드명 본문 확인 10 (`%PDF-` 헤더, PyMuPDF 열기 정상)
- 문서 버전: 파일명 날짜 + PDF 생성일 + 본문의 준법심의 번호(예: 더 심플 하나카드 L-26-2189(2026.09.29))를 manifest에 기록
- 발급 상태: 9종은 현재 공식 카드 목록에 있음. **BT 카드는 현재 PC·모바일 카드 목록에서 확인되지 않음**(신규 발급 종료 가능성, 미확인). 신규 발급 가능 여부는 모두 미확인.
- 대체 선정: 원더카드 2.0 DAILY/LIVING은 두 상품이 같은 16쪽 통합 PDF(15.9MB)를 공유해 예비 후보로만 두고 하나 원큐 카드로 대체. #MY WAY 카드는 상품 페이지에서 PDF 링크를 찾지 못해 제외.
- 주의: STYLE·PLAY PDF의 메타데이터 제목은 '상품약관'이나 본문은 상품 안내(연회비·서비스·제외 대상) 형식. 표 구조(혜택표·한도표)는 기존 검증처럼 기본 추출에서 깨질 수 있어 원문 이미지 대조가 필요. 카테고리 키워드 빈도는 제외 문구에도 등장하므로 혜택 존재 근거가 아님.

## D. 후속 분석 메모 (DB 설계·정규화 아님)

- 같은 대중교통 혜택, 다른 실적 기준: STYLE·PLAY(10만) ↔ K-패스 체크(30만/60만) ↔ K-패스 신용(50만/100만)
- 같은 상품명, 체크↔신용: K-패스 체크/신용, 더 심플 체크/신용 (실적 산정 범위: 일시불 vs 일시불/할부)
- 같은 제외 항목, 다른 적용 위치: 상품권 — 실적 제외(K-패스·더 심플) / 서비스 제외(STYLE·PLAY 공통) / 적립 제외(MULTI Any·원큐)
- 같은 신규 예외 문구 '최초 사용등록일~다음 달 말일': STYLE·PLAY·K-패스·더 심플에 등장, 적용 기준 구간이 카드마다 다름
- 실적 조건 없는 적립 카드(MULTI Any 체크·하나 원큐 신용) vs 혜택별 실적 조건 카드(BT·에너지 더블): 카드 단위 vs 혜택 단위 조건
- 확인 근거: 상품권의 실적 제외는 K-패스 체크·신용, 더 심플 체크·신용 원문의 ‘실적 제외 대상’ 목록에서 직접 확인(2026-10-30)
