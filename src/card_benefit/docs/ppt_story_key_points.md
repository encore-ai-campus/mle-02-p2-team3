# 카드 혜택 GraphRAG — PPT 핵심 스토리 메모 (V1 정리본)

> **상태:** 발표 기획안. PDF 파싱·조건 추출·Neo4j·GraphRAG·오답 검증은 구현·실증 전이며, 결과가 확인된 기능만 완료로 발표한다.
> 상세 개정 방향은 [V2 초안](ppt_story_key_points_v2_draft.md) 참고. 본 문서는 기존 V1의 간단한 핵심 스토리 정리본이다.

## 핵심 메시지

**"카드 혜택의 판단 근거를 추적하고, 잘못된 조건 해석과 변경 영향까지 검토하는 GraphRAG."**

하나카드 공식 상품설명서를 바탕으로 혜택·실적·제외 조건을 관계로 연결하고, 카드사 내부 담당자가 검토할 수 있는 근거 경로를 제시한다. 하나카드가 실제로 사용하는 시스템을 의미하지 않는다.

## 발표의 세 축

| 축 | PPT에서 보여줄 내용 | 핵심 질문 |
|---|---|---|
| **1. 판단 과정과 근거** | 질문 → 카드·혜택·조건 탐색 → 약관 원문 위치 제시 | 어떤 조건과 근거를 적용했는가? |
| **2. 오답 발견·개선** | 실제 재현된 오류 2~3건 → 원인 분석 → 수정 → 동일 질문으로 재검증 | 어디서 잘못 판단했고 어떻게 개선했는가? |
| **3. 조건 변경 영향 검토** | 특정 조건 변경을 가정 → 관련 카드·혜택·조항을 검토 후보로 추적 | 어떤 상품과 조항을 다시 확인해야 하는가? |

## 시연 예시 (가상 · 구현 후 검증 필요)

- **질문:** "상품권 구매가 전월실적에서 제외되는 카드와 관련 혜택은 무엇인가?"
- **판단 경로:** 카드 → 혜택 또는 카드 단위 조건 → 전월실적 제외 조항 → 원문 근거. 실제 적용 범위에 맞게 관계를 구성한다.
- **오류 검증:** 전월실적 제외와 할인·적립 제외를 혼동하지 않는지 동일 질문으로 비교한다.
- **영향 검토:** 제외 조건이 변경된다고 가정할 때 재검토가 필요한 카드·혜택·조항을 보여준다. 실제 카드사 공통 정책이나 자동 반영을 의미하지 않는다.

## 오답 사례 공개 원칙

1. 발표에서는 대표 2~3건만 보여주고, 전체 검증 기록과 재현 방법은 별도 문서에 둔다.
2. 실제 로그와 원문으로 검증된 경우만 '실제 오답'으로 표시한다. 미검증 내용은 가상 예시로 구분한다.
3. 개선 전후 정확성·조건 누락·근거 일치 여부를 같은 자료와 질문으로 비교한다. GraphRAG의 무오류를 주장하지 않는다.
4. 근거 부족·적용 범위 불확실성은 **판단 보류 및 사유 제시**로 처리한다.

## 마케팅 관련 내용 (선택적 후속 제안)

- **카드 고유 수식어, 검색 의도별 홍보 문구, 기간별 캠페인 문구 노출**은 기존 카드 상품 페이지나 CMS에서도 구현 가능한 기능이므로 **PPT 핵심 차별화 요소에서 제외**한다.
- 필요하다면 **카드사 승인 광고 문구와 공식 약관 사이의 정합성 검토**, **조건 변경 시 재확인할 문구 목록 추적** 정도를 후속 업무 활용 아이디어로만 언급한다.
- 마케팅 문구는 AI의 혜택 판단·검색 적합도·순위와 분리하고, 실제 구현하지 않은 기능은 제안으로 표시한다.

## 추천 PPT 흐름

**문제 제기 → 약관의 복합 조건 → 판단 경로 시연 → 실제 오답 원인과 개선·재검증 → 조건 변경 영향 분석 → 결과·한계·후속 활용**

> 우선 개발 목표는 공식 문서 기반 추출·검증과 관계 검색의 재현 가능성이다. 마케팅 기능 구현을 핵심 일정에 포함하지 않는다.
