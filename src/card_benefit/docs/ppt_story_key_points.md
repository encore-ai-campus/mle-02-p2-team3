# 카드 혜택 GraphRAG — PPT 핵심 스토리 메모

> **상태:** 발표 기획 아이디어 (미구현·미검증 기능 포함). 실제 카드사 운영 기능이라고 주장하지 않는다.

## 핵심 메시지

**"AI의 답변을 넘어, 판단 근거와 오류 개선 과정까지 보여주는 카드 혜택 검색."**

하나카드 여러 상품의 공식 약관을 대상으로, 사용자에게는 근거 있는 카드 검색을 제공하고 운영자에게는 조건 검토와 마케팅 문구 관리를 지원하는 **가상 서비스 제안**.

## 발표의 세 축

| 축 | PPT에서 보여줄 내용 | 핵심 질문 |
|---|---|---|
| **1. 판단 과정** | 질문 → 카드·혜택·실적·제외 조건 탐색 → 약관 원문 근거 표시 | 왜 이 카드가 검색·추천됐는가? |
| **2. 오답 분석·개선** | 실제 오류 사례 2~3개 → 원인(실적 제외/할인 제외 혼동 등) → 구조·검증 개선 → 재시험 | 잘못된 판단을 어떻게 발견·줄였는가? |
| **3. 카드사 마케팅** | 카드 고유 수식어 + 검색 의도별 문구 + 기간별 캠페인을 승인·분리 노출 | 카드 브랜드와 프로모션을 어떻게 운영할 수 있는가? |

## 시연 예시 (가상)

- 고객 질문: "커피 할인 카드 중 전월실적 조건이 맞는 상품을 찾아줘."
- **AI 분석 영역:** 후보 카드, 실제 혜택·실적·제외 조건, 출처(상품설명서 페이지·조항)를 안내.
- **별도 마케팅 영역:** 적합한 후보 카드에 한해 **[프로모션] ✨ 반짝반짝 빛나는 신규 카드 출시!** 등 **사전 승인된 문구** 표시.
- **운영 원칙:** 마케팅 문구는 약관상 혜택·판단 근거와 분리한다. 프로모션 때문에 부적합한 카드를 적합하다고 답하거나 광고를 중립적인 추천으로 위장하지 않는다.

## 카드별 고유 마케팅 수식어 (우선 노출 · 가상 예시)

**핵심 제안:** 검색어와 관계없이 **카드 자체에 붙는 고유한 브랜드 수식어**를 카드사가 승인해 등록한다. 검색 결과·카드 상세에서 일관되게 노출하여 카드별 정체성을 표현한다. 검색 의도별 문구, 기간별 캠페인 문구와 **서로 다른 개념**이다.

| 가상 카드 성격 | 카드 고유 수식어 | 보조 문구 |
|---|---|---|
| 쇼핑 특화 카드 A | **✨ 쇼핑할 때 더 빛나는 나의 카드** | 평범한 쇼핑에도 특별함을 더하다. |
| 라이프스타일 카드 B | **💖 내 일상을 조금 더 특별하게** | 매일의 소비에 나만의 혜택을. |
| 여행 특화 카드 C | **✈️ 떠나는 순간부터 설레는 혜택** | 여행을 준비하는 당신의 새로운 선택. |

> 위 카드명과 문구는 **PPT용 가상 사례**이며 하나카드의 공식 문구나 검증된 혜택이 아니다. 실제로 적용할 때는 카드사가 제공·승인한 문구를 우선 사용하고, 객관적 혜택처럼 오해될 표현은 약관과 대조한다.

### 서로 다른 3가지 마케팅 문구

| 유형 | 표시 기준 | 예시 |
|---|---|---|
| **① 카드 고유 수식어** | 카드 ID에 연결된 고정 브랜드 문구 | ✨ 쇼핑할 때 더 빛나는 나의 카드 |
| **② 검색 의도별 문구** | 커피·쇼핑 등 고객이 검색한 관심 주제와 실제 카드 혜택 | ☕ 커피 한 잔의 여유, 혜택까지 챙겨보세요. |
| **③ 기간별 캠페인 문구** | 신규 출시·행사 등 등록된 캠페인 기간 | 🎉 반짝반짝, 기다리던 신규 카드 출시! |

**검색 결과 화면 예시**

> **가상 쇼핑 특화 카드 A**  
> ✨ **쇼핑할 때 더 빛나는 나의 카드** ← *카드 고유 수식어*  
> **AI 혜택 분석:** 할인·전월실적·제외 조건과 공식 약관 근거  
> **[프로모션] 🛍️ 자주 하는 쇼핑, 혜택도 놓치지 마세요!** ← *검색 의도별 문구*  
> **[신규 출시 캠페인] 🎉 반짝반짝, 기다리던 신규 카드 출시!** ← *해당 캠페인이 유효할 때만*

**구현 아이디어(제안 단계):** 카드 고유 수식어는 카드별 승인 문구로 보관하고, 검색 의도별 문구와 기간별 캠페인은 별도 노출 규칙으로 관리한다. 세 종류 모두 **GraphRAG가 생성한 약관 판단과 분리**하고, 과장·오인 가능성 및 노출 우선순위는 운영자가 검토한다.

## 검색 의도 기반 마케팅 문구 (가상 · 카드사 승인 문구)

**기획 포인트:** 성별에 따라 문구를 단정해서 다르게 보여주기보다, **고객이 검색한 혜택·상황에 맞춰** 카드사가 승인한 메시지를 노출한다. 기존의 '반짝반짝 신규 카드' 문구는 **신규 출시 캠페인용 예시**로 유지한다.

| 고객 검색 의도·노출 상황 | 카드사 마케팅 문구 예시 |
|---|---|
| 신규 카드 찾기 / 신규 출시 | **✨ 반짝반짝, 기다리던 신규 카드 출시!** |
| 커피 할인 검색 | **☕ 커피 한 잔의 여유, 혜택까지 챙겨보세요.** |
| 쇼핑 할인 검색 | **🛍️ 자주 하는 쇼핑, 혜택도 놓치지 마세요!** |
| 생활비 절약 검색 | **💳 매일 쓰는 생활비, 내 소비에 맞는 혜택을 찾아보세요.** |
| 여행·해외 이용 검색 | **✈️ 여행의 설렘에, 내게 맞는 카드 혜택을 더해보세요.** |

모두 **PPT용 가상 문구**이며 실제 하나카드 광고·상품 혜택을 뜻하지 않는다. 검색 의도가 같더라도 **해당 혜택이 공식 약관으로 확인된 카드에만** 관련 문구를 연결한다.

### PPT 시연 예시

> **사용자 검색:** "커피 할인되는 카드 추천해 줘. 전월실적 조건도 알려줘."  
> **AI 혜택 분석:** 조건에 맞는 카드 A, 할인·실적·제외 조건 및 약관 근거 표시  
> **[프로모션 / 카드사 승인 문구] ☕ 커피 한 잔의 여유, 혜택까지 챙겨보세요.**  
> **다른 검색:** "새로 나온 카드 알려줘." → **[프로모션] ✨ 반짝반짝, 기다리던 신규 카드 출시!**

### 서비스 설계 시 구분할 사항

- **판단 영역:** GraphRAG가 혜택·실적·제외 조건을 원문 근거로 검색·설명한다.
- **마케팅 영역:** 운영자가 문구를 등록·승인하고 카드 ID, 검색 의도 태그, 캠페인 기간, 활성 상태를 지정한다.
- **노출 제어:** 검색 의도와 카드의 실제 확인된 혜택이 일치할 때만 별도 **[프로모션]** 영역에 표시한다. 광고 노출을 중립적인 검색 순위나 혜택 판단에 섞지 않는다.
- **검증/확장:** 문구 효과는 성별 선호를 추측하지 않고 추후 클릭률·A/B 테스트로 검증할 수 있다(현재 구현 범위 아님).
- **주의:** 문구에 미확인 할인율·한도 등 구체적 상품 조건을 생성하지 않는다. 실제 구현하지 않은 운영자 기능은 PPT에서 **제안 기능**으로 표기한다.

## 오답 사례 구성 원칙

1. **대표 2~3개만 PPT에 공개**하고 전체 검증 목록·재현 절차는 별도 문서/코드에서 제공.
2. 오류 사례는 **실제 약관과 실행 로그로 재현된 것만** '실제 오답'으로 제시. 미검증 예시는 '가상 시나리오'로 표기.
3. 동일한 질문·자료로 **개선 전후의 답변, 근거 일치, 조건 누락** 등을 비교. GraphRAG가 항상 정답이라는 주장 금지.
4. 근거가 부족하거나 조건 충돌 시 **판단 보류·검토 필요**를 명시.

## 추천 PPT 흐름

**문제 제기 → 판단 경로 시연 → 오답 발견·수정·재검증 → 카드 검색 UI + 분리된 마케팅 문구 → 활용 가치·한계**

> 우선 개발 범위는 **PDF 추출·검증 및 GraphRAG 판단**. 마케팅 노출·캠페인 관리 기능은 **추가 구현 후보**로 두고, 실제 구현 시에만 완료 기능으로 발표한다.
