# 카드 혜택 GraphRAG — PPT 핵심 스토리 메모

> **상태:** 발표 기획 아이디어 (미구현·미검증 기능 포함). 실제 카드사 운영 기능이라고 주장하지 않는다.

## 핵심 메시지

**"AI의 답변을 넘어, 판단 근거와 오류 개선 과정까지 보여주는 카드 혜택 검색."**

하나카드 여러 상품의 공식 약관을 대상으로, 사용자에게는 근거 있는 카드 검색을 제공하고 운영자에게는 조건 검토와 마케팅 문구 관리를 지원하는 **가상 서비스 제안**.

## 발표의 세 축

| 축 | PPT에서 보여줄 내용 | 핵심 질문 |
|---|---|---|
| **1. 판단 과정** | 질문 → 카드·혜택·실적·제외 조건 탐색 → 약관 원문 근거 표시 | 왜 이 카드가 검색·추천됐는가? |
| **2. 오답 분석·개선** | 실제 오류 사례 2~3개 → 원인(실적 제외/할인 제외 혼동 등) → 구조·검증 개선 → 재시험 | 잘못된 판단을 어떻게 발견·줄였는가? |
| **3. 카드사 마케팅** | 검색 결과에 운영자가 승인한 카드별 홍보 문구·기간·대상 노출 | 신상품과 프로모션을 어떻게 운영할 수 있는가? |

## 시연 예시 (가상)

- 고객 질문: "커피 할인 카드 중 전월실적 조건이 맞는 상품을 찾아줘."
- **AI 분석 영역:** 후보 카드, 실제 혜택·실적·제외 조건, 출처(상품설명서 페이지·조항)를 안내.
- **별도 마케팅 영역:** 적합한 후보 카드에 한해 **[프로모션] ✨ 반짝반짝 빛나는 신규 카드 출시!** 등 **사전 승인된 문구** 표시.
- **운영 원칙:** 마케팅 문구는 약관상 혜택·판단 근거와 분리한다. 프로모션 때문에 부적합한 카드를 적합하다고 답하거나 광고를 중립적인 추천으로 위장하지 않는다.

## 마케팅 문구 예시 (가상 · 카드사 승인 문구)

검색 결과의 혜택 판단과 구분된 **[프로모션] 영역**에 카드별로 표시한다. 아래는 발표용 예시이며 실제 하나카드 광고 문안이나 공식 혜택이 아니다.

| 노출 상황 | 카드별 마케팅 문구 예시 |
|---|---|
| 신규 카드 출시 | **✨ 반짝반짝, 기다리던 신규 카드 출시!** |
| 새 카드 강조 | **🌟 지금 주목할 신상 카드! 새로운 혜택을 만나보세요.** |
| 커피 혜택 검색 | **☕ 커피 한 잔의 즐거움, 이 카드의 혜택도 살펴보세요!** |
| 쇼핑 혜택 검색 | **🛍️ 장바구니가 즐거워지는 카드, 지금 확인하세요!** |
| 기간 한정 캠페인 | **🎉 이번 달 주목할 카드! 진행 중인 이벤트를 확인해 보세요.** |

**화면 시연 문안**

> AI 검색 결과: 사용자 조건에 부합하는 카드 A (혜택 조건 및 약관 근거 표시)  
> **[프로모션 · 카드사 등록 문구] ✨ 반짝반짝, 기다리던 신규 카드 출시!**  
> 카드사 승인 문구 · 노출 기간: 예시

**설계 주의:** 문구는 운영자가 등록·승인하고 카드 ID·노출 기간·상태에 연결한다. 실제 혜택·수수료·할인율은 문구로 임의 생성하지 않는다. 검색 결과의 적합성 판단이나 순위와 광고 노출을 구분한다.

## 오답 사례 구성 원칙

1. **대표 2~3개만 PPT에 공개**하고 전체 검증 목록·재현 절차는 별도 문서/코드에서 제공.
2. 오류 사례는 **실제 약관과 실행 로그로 재현된 것만** '실제 오답'으로 제시. 미검증 예시는 '가상 시나리오'로 표기.
3. 동일한 질문·자료로 **개선 전후의 답변, 근거 일치, 조건 누락** 등을 비교. GraphRAG가 항상 정답이라는 주장 금지.
4. 근거가 부족하거나 조건 충돌 시 **판단 보류·검토 필요**를 명시.

## 추천 PPT 흐름

**문제 제기 → 판단 경로 시연 → 오답 발견·수정·재검증 → 카드 검색 UI + 분리된 마케팅 문구 → 활용 가치·한계**

> 우선 개발 범위는 **PDF 추출·검증 및 GraphRAG 판단**. 마케팅 노출·캠페인 관리 기능은 **추가 구현 후보**로 두고, 실제 구현 시에만 완료 기능으로 발표한다.
