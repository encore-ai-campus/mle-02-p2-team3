## 1. 카드 엔진 → M0~M9 매핑표

| 번호 | 과제 | 카드 엔진에서 할 일 | 확인할 결과 | 담당(안) | 일정 |
| --- | --- | --- | --- | --- | --- |
| M0 | 주제·문서 확정 | 카드 2~3종 선정 (**전월실적 제외 항목이 겹치는 카드** 우선). 약관·상품설명서 목록표 작성(문서명·출처·버전·형식·활용 범위). 그래프로 답할 질문 확정: "제외 항목 X가 바뀌면 영향받는 카드·혜택은?" | 문서 목록표, 질문 3~5개 | PM + 문서·데이터 | 1일차 오전 |
| M1 | 문서 전처리 | PDF 텍스트 추출, 머리말·꼬리말 제거, 혜택·조항 단위 분할. 표(할인율·한도)·금액·%·업종명 보존. document_id / chunk_id / 페이지·조항 위치 부여 | 전처리 코드, 전후 예시 | 문서·데이터 | 1일차 오전 |
| M2 | 온톨로지 스키마 | 노드: `Card`, `Benefit`, `Condition`(유형: 전월실적/이용처/예외/한도), `Merchant`, `Clause`. 관계: `HAS_BENEFIT`, `REQUIRES`, `EXCLUDES`, `LIMITED_BY`, `APPLIES_TO`, `SOURCED_FROM`. **같은 제외 항목이 여러 카드에서 하나의 노드를 공유**하도록 설계 | 유형 정의·연결 규칙 표 | 지식 그래프 | 1일차 오후 |
| M3 | 추출 프롬프트 | 허용 유형·방향 고정, `evidence`(약관 문장)·`clause_id` 필수. **약관에 없으면 생성하지 않고, 근거 부족은 빈 배열**. 금액·비율은 원문 표기 유지 | 실제 사용 프롬프트 | LLM 추출 | 1일차 오후 |
| M4 | 자동 추출 파이프라인 | 청크 입력 → LLM → JSON 파싱·스키마 검증 → 저장. 파싱 실패·허용 외 유형·누락 값 처리 | 실행 코드, 추출 JSON | LLM 추출 | 2일차 오전 |
| M5 | 중복 개체 정규화 | "간편결제 / 간편 결제 / 페이 결제" 등 표기 통합, **카드 간 같은 제외 항목은 하나의 개체로 연결**. 오병합 점검: "전월실적 30만"과 "40만"은 별개 조건으로 유지 | ER 코드, 전후 사례 표 | 지식 그래프 | 2일차 오전 |
| M6 | 스키마 매핑·Neo4j 적재 | 정규화 ID로 노드·엣지 변환, `MERGE`로 재적재 시 중복 방지, 관계 속성에 `document_id`·`chunk_id`·`evidence` 보존 | 적재 코드, 적재 건수 | 지식 그래프 | 2일차 오후 |
| M7 | Cypher 조회·시각화 | ① 카드별 혜택·조건 조회 ② **제외 항목 변경 시 영향 카드·혜택 추적(핵심 시연)** ③ 판정 경로(조건 → 혜택 → 조항). Neo4j Browser 시각화 + 해석 | 쿼리, 화면, 설명 | 지식 그래프 | 2일차 오후~3일차 오전 |
| M8 | 정확성·정합성 검증 | 원문–트리플–정규화–그래프 대조. 검토 대상 선정 기준·건수 기록. 오류 6분류(원문에 없는 관계 / 방향 / 중복 / 오병합 / 스키마 위반 / 적재 누락). 필요 시 골든 질문 표본(정답 기준·표본 수·계산법 기록) | 검증 기록, 오류 보완 사례 2~3건 | LLM 추출 + 지식 그래프 | 3일차 오전 |
| M9 | 통합 시연·회고 | 문서 → 그래프 → **MCP 호출까지 한 흐름 시연**. 전원이 담당 구간 설명, KPT, README | 실행 안내, 회고 | 전원 / PM | 3일차 오후 |

### MCP 연동 범위 (필수 완료 후, 3일차)

Neo4j 위에 얇게 얹는 도구 2~3개로 제한합니다. 새로운 판단 로직은 만들지 않습니다.

| MCP 도구(안) | 내부 동작 | 시연 의미 |
| --- | --- | --- |
| `get_card_benefits(card)` | M7-① 쿼리 호출 | 카드별 혜택·조건·근거 조항 반환 |
| `find_affected_by_condition(condition)` | M7-② 쿼리 호출 | 조건 변경 시 영향 카드·혜택 반환 |
| `explain_judgment(card, benefit)` *(여유 시)* | M7-③ 경로 반환 | 근거 경로 설명 |

- 시연: 같은 질문을 **Neo4j Browser의 Cypher 결과**와 **MCP 도구 응답**으로 실행해 결과가 일치하는지 확인
- **컷라인:** 3일차 오전 종료 시 M8 검증이 끝나지 않았다면 MCP는 도구 1개(`get_card_benefits`)만 남기고 나머지는 후속 과제로 기록
