## 3. 한계 (이번 판정이 말하지 않는 것)
- **청크 = 페이지 전체**이므로, 이 검사는 "페이지 텍스트가 페이지 청크로 옮겨졌는지"만 확인한다. 청크 내용이 PDF 원문과 맞는지는 별도 확인 대상이다.
- **표·그림 내용은 확인되지 않았다.** 두 페이지에 벡터 도형(282개, 318개)이 있고, 품질 항목 `has_visual`이 True다. 표 셀의 행·열 대응이나 그림 속 글자는 텍스트 추출로 보장되지 않는다 (`document_reader.py` 주석과 일치).
- **PDF 화면 확인은 하지 않았다.** 원문 시각 대조는 이번 범위 밖으로 정했다 (`04_decision.md` 결정 항목 3번).

## 4. 실행 환경
- 저장소의 `uv run --locked` 대신, 저장소 밖 scratch 가상환경을 썼다. 저장소 `.venv`를 만들지 않으려는 목적이다.
- 버전은 `uv.lock`과 같다: PyMuPDF 1.28.2, pypdf 6.19.0 (`pypdf[image]`), python-dotenv 1.2.4. Python 3.12.
- 실행 명령: `PYTHONPATH=src:src/card_benefit python -m payment_card.file_pipeline.doc_index.traceability --pdf <사본> --output <JSON> --expected-sha256 <해시> --expected-page-count 2` (저장소 루트에서)
- 원본 PDF는 ZIP에서 임시 폴더로 꺼낸 사본이다. 원본 ZIP과 manifest는 수정하지 않았다.
