# SQL 참고 명세

이 폴더의 `card_benefit_schema.sql`은 참고용 명세다. 실행 코드가 자동 적용하지 않으며, 팀 DB에 적용하기 전에는 팀 합의가 필요하다.

| 항목 | 기록 |
|---|---|
| 자료 이름 | `card_benefit_schema.sql` |
| 저장소 안 위치 | `src/card_benefit/payment_card/file_pipeline/sql/card_benefit_schema.sql` |
| 원본 형태(문서/메일/메신저/구두 등) | 확인 필요 |
| 전달자(이름 또는 역할, 연락처 제외) | 팀원 (사용자 확인, 2026-11-03). 이름·연락처는 기록하지 않는다 |
| 전달일 | 확인 필요 |
| 전달 경로 | 확인 필요 |
| 원본 보관 위치(저장소 밖 경로만) | 확인 필요 |
| 원본 해시(SHA-256) | 확인 필요 |

## 사용 전 합의

팀 DB에 적용하기 전에 스키마 이름, 테이블 접두사, RLS 정책, pgvector 확장 사용 여부를 합의한다. 이 참고 명세는 `graph/schema.sql`의 `public` 및 `pf_` 접두사 설계와 별개로 다룬다. 관련 비교 기록은 [스키마 비교](../../../../../docs/작업이력/2026-11-03-스키마비교-참고명세와pf-laptop.md)에 있다.
