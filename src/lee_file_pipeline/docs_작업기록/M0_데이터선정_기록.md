# M0 — 카드 문서·데이터 선정 기록

상태: 카드 상품설명서 도메인은 승인됐다. 아래 하나카드 문서는 저장소 메타데이터와 기존 파일럿 기록으로 확인되는 대표 문서 후보이며, 과제 제출용 대표 문서로의 최종 선정은 미정이다. 이용·공유 범위와 실제 그래프 질문도 팀 결정이 남아 있다. 따라서 M0는 부분 완료다.

## 주제와 과제 범위

- **주제:** 카드 상품설명서에서 혜택·조건·한도·대상을 추출하고, 카드와의 연결을 지식 그래프로 조회한다.
- **개체:** `Card`, `Benefit`, `Condition`, `Limit`, `Target`. 추출 결과의 네 혜택 개체는 `ONTOLOGY_V1`에 정의되고, `Card`와 카드별 `OFFERS` 연결은 그래프 구성 단계에서 붙는다.
- **질문 후보(확정 전):**
  1. 특정 카드가 제공하는 혜택과 각 혜택의 조건·한도·대상은 무엇인가?
  2. 특정 가맹점 또는 대상에 적용되는 혜택은 무엇이며, 출처 문서와 쪽은 어디인가?
- 카드명, 대상 가맹점, 질문 문구와 제출 시연 질문은 팀이 확정해야 한다.

## 해석 경계와 남은 결정

- 이 기록은 저장소의 기존 문서와 비본문 메타데이터를 대조한 것이다. PDF 본문, `.env`, DB, LLM, 웹은 열거나 사용하지 않았다.
- manifest의 URL·파일명 날짜·수집 상태를 현재 웹 상태나 공식 게시일 확인으로 확대 해석하지 않는다.
- 기존 파일럿의 통과는 해당 문서의 추적성과 기록된 표본 대조에 관한 결과다. 표·그림, 혜택 추출 정확도, 그래프 적재, 과제 전체의 유효성을 보증하지 않는다.
- M0를 완료하려면 팀이 대표 문서, 공식 출처/버전으로 제출할 기준, 이용·공유 범위, 2–3개의 구체적인 그래프 질문을 확정해야 한다. 원문 공유 여부와 비밀정보 점검도 제출 방식에 맞춰 확인해야 한다.
