# M9 — 통합 시연·회고 작성 틀

상태: 작성 틀. 실제 실행 결과와 팀원 정보는 시연 후 채운다.

## 시연 목표

카드 상품설명서에서 확인한 개체·관계가 근거 위치를 유지한 채 추출, 정규화, 그래프 매핑, Cypher 조회까지 이어지는 모습을 보여준다. 확인하지 않은 단계는 시연 완료라고 표시하지 않는다.

## 시연 순서

| 순서 | 담당 | 보여 줄 내용 | 사용할 증거 | 상태 |
|---|---|---|---|---|
| 1. 데이터·질문 | 미정 | 문서 선정 이유, 출처·버전·이용 범위, 그래프로 답할 질문 | [M0 기록](M0_데이터선정_기록.md) | 문서 메타데이터 보완 필요 |
| 2. 전처리·추적 | 미정 | 인덱스→페이지→청크 ID와 위치, 표본 전후 예시 | 기존 `doc_index/`, `chunking/` 안내 | 실연 자료 선택 필요 |
| 3. 스키마·프롬프트 | 미정 | 개체·관계 허용 규칙과 근거 요구 | [`추출 계약`](../extraction_혜택추출/과제_추출-계약.md) | 준비 중 |
| 4. 추출·정규화 | 미정 | JSON 검증, 대표명/별칭 검토와 관계 ID 갱신 | 실제 공유 가능한 결과 요약 및 사람 검토 사례 | 팀 실행·검토 필요 |
| 5. 그래프 조회 | 미정 | Neo4j 노드·관계, 선택 질의, 결과 해석 | [`그래프 검증 안내`](../graph_그래프/과제_그래프-검증-안내.md) | DB/Browser 실행과 캡처 필요 |
| 6. 원문 대조 | 미정 | 검토 표본, 근거·방향·중복·오류 수정 | 그래프 검증 안내의 검토 기록 | 사람 판정 필요 |
| 7. 회고 | 전원 | 개인 기여, 막힌 점, 조치 이유, 남은 한계 | 아래 KPT | 팀 작성 필요 |

## 실제 시연 증거

| 시연 일시 | 실행 단계·질문 | 실제 증거 위치(파일/폴더 링크 또는 경로) | 실행 ID·로그 ID | 실행자 | 확인 상태 |
|---|---|---|---|---|---|
|  |  |  |  |  | 미실행/미확인 |

## 시연 종료 체크

- [ ] 사용 문서의 출처·버전·이용 범위를 제시했다.
- [ ] 시연 질문과 Cypher가 서로 대응한다.
- [ ] 개체·관계·근거를 원문 위치까지 추적했다.
- [ ] 실제로 사람이 확인한 검토 건수와 미검토 범위를 구분했다.
- [ ] Neo4j 적재·조회와 화면 캡처를 팀이 실행해 확인했다.
- [ ] 정밀도/성공률 숫자를 쓸 경우 정답 기준·표본 수·분모·계산법을 함께 적었다.
- [ ] KPT와 팀원별 기여를 전원이 확인했다.

체크되지 않은 항목은 미완료 또는 미확인으로 남긴다.
