# 챗봇 자료와 관계도 표시 검토

## 범위와 흐름

- 확인 범위: 합성 DB 응답을 이용한 검색 결과 → 출처 구성 → 관계도 표시, 화면 실패 표시. 실제 DB, 실제 카드 원문과 LLM 답변은 확인하지 않았다.
- 사용자 담당 화면은 기존 `rag.explore`의 노드·관계를 받은 뒤 `collect_sources`로 자료를 구성한다. 관계도는 개발자 모드의 `검색 과정 → 근거 그래프`에서 렌더링한다.
- [합성 검증 코드](../tests_테스트/test_chat_graph_display.py)는 카드·혜택·조건·한도·문서 연결과 같은 이름의 다른 카드, 자료 없음, 조회 오류, 표시용 복사본을 확인한다.

## 화면 관계 이름

| 내부 값 | - 화면 표시 |
|---|---|
| `OFFERS` | - 제공 |
| `HAS_CONDITION` | - 조건 |
| `HAS_LIMIT` | - 한도 |
| `APPLIES_TO` | - 적용 대상 |
| `EXCLUDES` | - 제외 대상 |
| `MUTUALLY_EXCLUSIVE` | - 상호 배타 |
| `SUPPORTED_BY` | - 문서 근거 |

화면을 그리기 위한 깊은 복사본의 관계 값만 바꾼다. 원본 그래프의 관계 값·ID·방향과 노드 종류는 그대로이며, 목록에 없는 관계는 원래 값으로 표시한다. 노드 종류 `Card`, `Benefit` 등은 이번 변경에서 한글화하지 않았다. 팀 공용 그래프 렌더러는 변경하지 않았다.

## 자료 표시에서 확인한 사항

- 문서 뷰의 `props.fp_id`가 `doc:`과 문서 해시로 구성되는 경우, 문서 출처의 해시를 표시하도록 수정했다. 이것은 파일명을 복원하는 기능이 아니다.
- 사용자 화면은 현재 `collect_sources(subgraph)`를 호출하며 문서별 근거 행을 별도로 전달하지 않는다. 따라서 문서 쪽 번호를 확인할 근거가 없으면 `자료에서 확인하지 못함`으로 둔다. 문서 노드의 요약에 적힌 임의의 최소 쪽을 질문의 정확한 근거 쪽으로 추정하지 않는다.
- 검색된 혜택의 `source_text_pages` 문자열은 합성 흐름에서 쪽 번호로 표시됐다. 공용 `rag._node_dict`는 리스트 속성을 제외하므로 같은 값이 리스트로 들어오면 이 단계에서 빠질 수 있다. 파일 기반 원문 구간 생성 코드는 문자열을 쓰지만, 실제 DB에 저장된 형태는 확인하지 않았다.
- 자료가 없는 합성 결과는 확인하지 못했다는 문구를 표시한다. 합성 조회 오류는 요청 처리 오류를 표시하고, 직후 화면을 다시 실행해 오류가 사라지는 문제를 수정했다.
- 조회 범위에는 노드 수 제한이 있고, 문서 연결 뷰에는 노드별 문서 수 제한이 있다. 화면에 없다는 사실만으로 원문이나 DB 전체에 해당 자료가 없다고 단정할 수 없다.

## 검증과 남은 일

- 2026-11-08 로컬: 사용자 테스트와 기존 관련 테스트 `509 passed, 4 subtests passed in 63.85s`. 사용자 폴더 테스트 단독 `29 passed in 5.05s`.
- 합성 DB 응답·가짜 LLM·Streamlit 테스트와 생성 HTML을 사용했다. 실제 브라우저에서 접속해 본 결과가 아니다.
- 실제 문서 제목·해시·쪽·카드 연결, 리스트형 쪽 번호의 실 DB 존재 여부, 생성 답변의 원문 일치 여부는 미확인이다. 실제 확인에는 별도로 허용된 읽기 전용 접속 또는 사용자의 실행 결과가 필요하다.

## 실제 연결 확인을 위한 사용자 검토표 — 아직 실행하지 않음

1. 골든셋을 제외한 확인 가능한 카드·원문 문서를 고르고 문서 버전과 쪽 번호를 적는다.
2. 허용된 환경에서 챗봇에 질문한 뒤 카드명, 혜택, 조건·한도와 문서 식별·쪽 표시를 원문과 각각 비교한다. 원문 전체나 접속 정보는 기록에 넣지 않는다.
3. 개발자 모드의 근거 그래프에서 연결 방향과 한글 관계 이름을 확인하고, 화면에 없는 항목은 DB 전체에 없다고 단정하지 않는다.
4. 각 항목을 `일치`, `불일치`, `화면에서 확인 불가`, `조회 오류`로 구분한다. 문서 쪽 번호를 표시할 근거가 제공되지 않으면 미확인으로 기록한다.
5. 리스트형 쪽 번호가 실제로 저장되는지와 다른 카드의 근거가 섞이는지 확인한다. 이 항목은 합성 테스트만 통과한 상태다.
