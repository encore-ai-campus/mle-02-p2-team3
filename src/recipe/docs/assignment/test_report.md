## 4. 실패·주의 사항

- **Q2 `common_ingredients` 순서 비결정**: `collect()` 결과라 같은 DB에서도 실행마다 원소 순서가 다를 수 있습니다. 노트북 1차 실행에서 테스트 DB와 운영 DB 비교가 이 순서 때문에 False로 나와, 목록 안을 정렬해 비교하도록 고쳤습니다. 숫자·레시피·순위는 같았습니다. 화면 표의 공통 재료 나열 순서도 고정되지 않습니다(값은 같음).
- 재료가 하나도 연결되지 않은 레시피 8개(반찬 5개 포함)가 있습니다. 재료 줄이 사전과 정확히 일치하지 않아 보류된 경우입니다.
- 조리 단계가 없는 레시피 1개(`비타 오이 물김치` 중 하나)는 Q5에서 `empty`(0건)로 안내됩니다.
